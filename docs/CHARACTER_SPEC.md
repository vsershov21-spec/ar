# ТЗ на персонажа: 3D-модель и видео-спрайты

Персонаж — **близнец СберКота**: тот же молодой взрослый кот (не подросток, не котёнок), меняются только
одежда, аксессуары, эффекты, звуки и реплики. Внешность: серо-голубой мех, белая мордочка и грудка, зелёные глаза.

## 1. Пропорции (по гайду и официальным кадрам СберКота)

| Параметр | Значение |
|---|---|
| Рост (гайд) | ≈ 65 см (в сцене масштаб не физический — см. MECHANICS.md) |
| Голова | **38–40% роста**, голова **шире тела** |
| Щёки | пушистые, выступают за линию головы |
| Хвост | короткий |
| Пальцы | **4** на лапе |
| Ноги | короткие (≈17% роста) |
| Возраст | молодой взрослый кот: «детские» пропорции головы, но без младенческой пухлости |

Близнецы (Хулиган, Блёстка) — **те же пропорции и та же база**, отличаются только скинами одежды.
Проверочная заглушка с этими пропорциями — `src/character/rigCat.ts` (`?char=rig`).

## 2. Риг

- **Mixamo-совместимый гуманоид**: `Hips, Spine, Spine1, Spine2, Neck, Head, Left/RightShoulder, Arm, ForeArm, Hand,
  UpLeg, Leg, Foot, ToeBase`, пальцы — 4 на руку (`Index, Middle, Ring, Pinky` или `Thumb` + 3 — согласовать).
  Имена **без префикса** `mixamorig:` (код его отрезает, но лучше без него).
- **Корневая кость `Root`** под `Hips` — для root motion (прыжок, сальто, кувырок, бег домой).
- **Хвост**: 4 кости `Tail1..Tail4` от `Hips`.
- **Уши**: по 2 кости — `LeftEar1, LeftEar2, RightEar1, RightEar2`.
- **Челюсть** `Jaw` (от `Head`) — для открытия рта, если нет блендшейпов.
- **Веки** `LeftEyelid, RightEyelid` (или блендшейпы моргания).
- Rest pose — A-pose или T-pose, лицом в **+Z**, вверх **+Y**, ступни на y=0, единицы — метры (рост ≈ 0.65).

## 3. Блендшейпы (morph targets)

| Имя | Назначение |
|---|---|
| `blink_L`, `blink_R` (или `blink`) | моргание |
| `smile`, `smirk` | улыбка, ухмылка (Хулиган) |
| `wink_L`, `wink_R` | подмигивание |
| `mouth_A`, `mouth_E`, `mouth_O`, `mouth_U`, `mouth_M` | виземы для липсинка (маппинг Rhubarb → блендшейпы в `src/lipsync/visemes.ts`) |
| `cheeks_gum` | надутые щёки (жвачка) |
| `brow_up`, `brow_down`, `brow_sad` | брови: удивление, недовольство, грусть |
| `eyes_squint`, `eyes_wide`, `eyes_spiral` | прищур, широко открытые, спирали (головокружение) |
| `tongue_out` | язык (дразнится) |
| `blush` | румянец (можно текстурой-наложением) |

Пресеты лица из этих блендшейпов — `content/face.json`. Полный список клипов — `content/animations.json` (71 клип, приоритеты P0–P2).

Маппинг визем Rhubarb: A→`mouth_M`, B→`mouth_E`×0.4, C→`mouth_E`, D→`mouth_A`, E→`mouth_O`, F→`mouth_U`,
G→`mouth_M`×0.4+`mouth_E`×0.3, H→`mouth_A`×0.45, X→покой.

## 4. Одежда и аксессуары — «скины» на одном скелете

- Отдельные меши, привязанные к тому же скелету: `Hoodie_Hooligan`, `Cap_Hooligan`, `Hoodie_Glitter`, `Bow_Glitter`, …
  Переключение персоны = показать/скрыть меши (`persona.glb.show/hide` в JSON, подстроки имён).
- **Хулиган**: чёрное худи с бирюзовым кантом, кепка козырьком назад (лайм), жвачка (розовая).
- **Добряк**: молочное худи с мятной оторочкой, вязаный персиковый шарф, носки-тапочки; реквизит — кружка какао, колечко для мыльных пузырей.
- **Блёстка** (сестра-близняшка, тот же возраст): лавандовое худи, мятные/золотые акценты, бант-звёздочка, юбка-пачка, блёстки на хвосте.
- **Нашивка Сбера** — в текстуре одежды на **левой груди** (у кота слева, у зрителя справа), UV-остров нашивки
  **фиксирован** во всех вариантах худи (чтобы заменить логотип одной текстурой).

## 5. Бюджет

| | |
|---|---|
| Треугольники | ≤ 20 000 (всё вместе, включая одежду всех персон) |
| Материалы | 1 материал, атлас 2048×2048 (baseColor + ORM + normal по возможности) |
| Файл | GLB + Draco (+ KTX2 по возможности), **≤ 5 МБ** |
| Кости | ≤ 70 |

Положить в `public/models/` (новое имя файла при каждой версии — долгий кэш) и прописать в `src/config.ts → ASSETS.glb`.
Режим проверки: `?debug&char=glb` — кнопки всех клипов в панели.

## 6. Клипы

Имена клипов в GLB = ключи ниже (регистр не важен). Если клипа нет — работает процедурная заглушка.
**In-place** — корень не смещается (перемещение делает код: ходьба по карте); **root motion** — смещение/вращение
корня в самом клипе (`Root`).

| Клип | Длит., с | Петля | Движение | Комментарий |
|---|---|---|---|---|
| `idle` | 4 | ✓ | in-place | дыхание, хвост, уши, моргание; бесшовная петля |

| `run` | 0.6 | ✓ | in-place | |
| `jump` | 1.0 | | root motion (Y) | присед → прыжок → приземление со сквошем |

## 7. Видео-спрайты (2D-режим, альтернатива 3D)

Используются, если персонаж рендерится видео/кадрами (например, из image-to-video пайплайна).

| Параметр | Требование |
|---|---|
| Кадр | **9:16**, кот целиком, запас 5% по краям |
| Фон исходника | хромакей **#00FF00** (ровный, без теней и бликов на фоне) |
| FPS | 24–30 |
| Выход | **.mov HEVC с альфой** (Safari/iOS), **.webm VP9 с альфой** (Chrome/Android), **PNG-кадры** (запасной, атлас) |
| Точка опоры | лапы на одной высоте во всех клипах; указать в манифесте `anchor.y` (доля высоты от верха, сейчас 0.985) |
| Петли | idle/talk/listen/walk — бесшовные (первый кадр = последнему + 1) |
| Размер | 720×1280 для HEVC/VP9 (≈1–2 МБ на 4 с), атлас — до 2048² |
| Рот | для липсинка: голова в кадре без закрытия рта лапами в talk-клипе; либо отдельные кадры рта (см. ниже) |

Подключение: `public/video/sprites/manifest.json` → `personas.<id>.clips.<clip>.video = { "hevc": "video/…mov", "webm": "video/…webm" }`.

Команды конвертации (ffmpeg):
```bash
# хромакей → PNG-кадры с альфой
ffmpeg -i src.mov -vf "chromakey=0x00FF00:0.12:0.05,despill=green" frames/%04d.png
# VP9 с альфой
ffmpeg -framerate 30 -i frames/%04d.png -c:v libvpx-vp9 -pix_fmt yuva420p -b:v 2M out.webm
# HEVC с альфой (только macOS, VideoToolbox)
ffmpeg -framerate 30 -i frames/%04d.png -c:v hevc_videotoolbox -alpha_quality 0.75 -tag:v hvc1 -b:v 3M out.mov
```

**Рот в спрайт-режиме.** Набор PNG/WebP форм рта Rhubarb **A–H, X** (`public/video/sprites/mouth/`, сейчас — заглушки),
оверлей поверх лица в позе с закрытым ртом. Для каждой позы с говорением в манифесте — `mouth: [x, y, ширина]`
(доли кадра). Формы рта рисовать в стиле финального образа, 128×96, центр — середина губ.
