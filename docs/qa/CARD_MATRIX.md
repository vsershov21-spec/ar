# Карта: матрица съёмки для стенда `card:eval`

Зачем: этап 1 «Карта» принимается по цифрам (посадка p90 ≤ 3 с, 0 ложных посадок, кот в ±5 мм при движении
25–45 см и наклоне 20–70°, ≤ 1 потери за 5 мин с восстановлением ≤ 1,5 с, без пересадки «не туда»). Цифры даёт
`npm run card:eval` — он прогоняет записи кадр за кадром через настоящий трекер (docs/CARD_DETECTION.md, «Стенд
записей»). Нужны **записи чистой камеры с гироскопом** — запись экрана с котом поверх карты годится плохо.

## Как снимать на iPhone (режим `?rec`)

1. Открыть `https://ar.vershov.com/lab/?rec=ИМЯ&debug` (или ссылку со страницы `/test` — тогда работает и в mvp/pilot).
   ИМЯ — по правилу ниже, например `?rec=d011_wood_day_approach_1`.
2. Разрешить камеру и «Движение и ориентация» (без гироскопа запись вдвое менее полезна).
3. **Номер карты закрыть** непрозрачной наклейкой/малярным скотчем (имя и срок тоже). Приложение дополнительно
   размывает нижние 60 % карты при записи, но это страховка, а не защита: пока карта не найдена, размыть нечего.
4. Кнопка «● Запись камеры» сверху → снять движение (5–20 с) → «■ Стоп» → «Поделиться записью» (AirDrop на Mac,
   «Файлы», Telegram «Избранное») или «Скачать». Сохраняются два файла: `ИМЯ_дата.mp4` и `ИМЯ_дата.json`
   (время кадров, гироскоп, фокус и задержка камеры трекера) — **нужны оба**.
5. Пишется кадр камеры 640 px по длинной стороне (кадр трекера ×2), без кота и интерфейса. Кот в это время работает
   как обычно — можно смотреть, где он сидит.

Снимать с руки, как ребёнок: телефон в портрете, карта на столе, 20–45 см.

## Правило имени

`d<дизайн>_<стол>_<свет>_<движение>_<дубль>`:
- дизайн — номер по каталогу (`d011`, `d121`) или короткое имя (`dmir` — карта МИР продакта);
- стол — `white`, `wood`, `dark` (тёмный или пёстрый/клетчатый);
- свет — `day` (дневной), `lamp` (тёплая лампа), `dim` (тусклая комната);
- движение — из списка ниже;
- дубль — 1, 2, …

Негативы — `neg_<предмет>_<стол>_<свет>_<дубль>` (`neg_tinkoff_wood_day_1`, `neg_book_white_lamp_1`): стенд считает
любую посадку на них ложной.

## Матрица

**Карты: 10–15 дизайнов Сбера.** Обязательно: зелёная классика, чёрная, белая/светлая, СберKids со знаком, детские
без знака на лицевой стороне (041 зайчик, 121 грифон, 123/125 осьминог), вертикальная, с серебряным чипом,
«трудные» по стенду (022, 023, 048, 073, 147 — светлая рамка, рисунок до края), карта МИР продакта.

**Столы: 3** — белый, дерево, тёмный или пёстрый (клетчатая скатерть, узор).

**Свет: 3** — дневной, тёплая лампа вечером, тусклая комната.

**Движения** (каждое — отдельная запись 5–20 с; первые 2 с карта уже в кадре, телефон почти неподвижен):

| код | что делать | что проверяет |
|---|---|---|
| `approach` | с 45 см медленно приблизить до 25 см (2–3 с), подержать, отдалить | масштаб кота, дрейф при приближении |
| `tilt` | на ~28 см наклонять телефон над картой от 20° (почти сверху) до 70° (почти сбоку) и обратно | дрейф при наклоне (это облёт — телефон сдвигается) |
| `orbit` | обойти карту по дуге на ~30 см (60–90° по кругу) | дрейф при сдвиге телефона |
| `shake` | 1–2 с быстро потрясти телефон (±10°), потом держать | задержка камеры, срыв ведения |
| `finger` | положить палец на знак Сбера на 2–3 с, потом на угол карты | перекрытие |
| `half` | увести карту наполовину за край кадра на 2–3 с и вернуть | частичная видимость, потеря и восстановление |
| `play` | 1–2 мин «играть»: как ребёнок, всё вперемешку, уводить камеру и возвращать | потери на 5 мин, пересадки |

Минимальный набор на дизайн: `approach`, `tilt` на всех трёх столах при дневном свете + `tilt` при лампе и при
тусклом свете (5 записей). Полный — 3 × 3 × 6 движений. `play` — по 2–3 записи на 3–4 дизайна.

**Негативы: 10** — карты других банков (обязательно зелёные: Тинькофф/«Т», ВТБ, Альфа, МИР без Сбера), книга,
пульт, телефон экраном вверх и вниз, визитка, пачка печенья/коробка, тетрадь. Каждый — 10–15 с с движением `tilt`.

## Как выложить на сервер

Сырые записи (даже с наклейкой) в git **не кладём**: папка записей — вне репозитория.

```bash
# на Mac: проверить и размыть номер ещё раз (лист кадров — глазами)
npm run card:blur -- ~/Downloads/d011_wood_day_tilt_1_20261119-101500.mp4 out/d011_wood_day_tilt_1.mp4 --preview
# сайдкар .json копируется рядом сам; затем на сервер
scp out/d011_wood_day_tilt_1.{mp4,json} server:/srv/ar-extra/card-rec/2026-11-19/
```

Если запись сделана не через `?rec` (камера телефона, запись экрана), рядом можно положить `eval.json` с обрезкой
области камеры, углом обзора и масками (формат — `tests/card/eval/clip.ts`), разметку углов `ИМЯ.gt.json` — по желанию.

## Прогон

```bash
npm run card:eval -- /srv/ar-extra/card-rec/2026-11-19            # отчёт в docs/qa/card-eval/<дата>.md + .json
npm run card:eval -- /srv/ar-extra/card-rec --baseline docs/qa/card-eval/2026-11-18.json   # регрессия: код выхода 1
npm run card:eval -- --synth                                         # синтетика с истинными углами (без записей)
```

В отчёт идут только цифры и имена файлов; кадры записей — нет.

Время воркера по умолчанию — мс этого компьютера × 2,5: на занятой машине (параллельные прогоны) цифры гуляют.
Для сравнения версий — `--worker-ms 45` (одинаковая задержка воркера).
