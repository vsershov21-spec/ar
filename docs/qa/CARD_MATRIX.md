# Карта: матрица съёмки для стенда `card:eval`

Зачем: этап 1 «Карта» принимается по цифрам (посадка p90 ≤ 3 с, 0 ложных посадок, кот в ±5 мм при движении
25–45 см и наклоне 20–70°, ≤ 1 потери за 5 мин с восстановлением ≤ 1,5 с, без пересадки «не туда»). Цифры даёт
`npm run card:eval` — он прогоняет записи кадр за кадром через настоящий трекер (docs/CARD_DETECTION.md, «Стенд
записей»). Нужны **записи чистой камеры с гироскопом** — запись экрана с котом поверх карты годится плохо.

## Как снимать на iPhone (режим `?rec`)

1. Открыть `https://ar.vershov.com/lab/?rec=ИМЯ&debug` (или ссылку со страницы `/test` — тогда работает и в mvp/pilot).
   ИМЯ — по правилу ниже, например `?rec=d011_wood_day_approach_1`.
2. Разрешить камеру и «Движение и ориентация» (без гироскопа запись вдвое менее полезна).
3. **Номер карты закрыть** непрозрачной наклейкой/малярным скотчем (имя и срок тоже). Приложение дополнительно
   размывает нижние 60 % карты при записи, но это страховка, а не защита: пока карта не найдена, размыть нечего.
4. Кнопка «● Запись камеры» сверху → снять движение (5–20 с) → «■ Стоп» → «Поделиться записью» (AirDrop на Mac,
   «Файлы», Telegram «Избранное») или «Скачать». Сохраняются два файла: `ИМЯ_дата.mp4` и `ИМЯ_дата.json`
   (время кадров, гироскоп, фокус и задержка камеры трекера) — **нужны оба**.
5. Пишется кадр камеры 640 px по длинной стороне (кадр трекера ×2), без кота и интерфейса. Кот в это время работает
   как обычно — можно смотреть, где он сидит.

Снимать с руки, как ребёнок: телефон в портрете, карта на столе, 20–45 см.

## Правило имени

`d<дизайн>_<стол>_<свет>_<движение>_<дубль>`:
- дизайн — номер по каталогу (`d011`, `d121`) или короткое имя (`dmir` — карта МИР продакта);
- стол — `white`, `wood`, `dark` (тёмный или пёстрый/клетчатый);
- свет — `day` (дневной), `lamp` (тёплая лампа), `dim` (тусклая комната);
- движение — из списка ниже;
- дубль — 1, 2, …

Негативы — `neg_<предмет>_<стол>_<свет>_<дубль>` (`neg_tinkoff_wood_day_1`, `neg_book_white_lamp_1`): стенд считает
любую посадку на них ложной.

## Матрица

**Карты: 10–15 дизайнов Сбера.** Обязательно: зелёная классика, чёрная, белая/светлая, СберKids со знаком, детские
без знака на лицевой стороне (041 зайчик, 121 грифон, 123/125 осьминог), вертикальная, с серебряным чипом,
«трудные» по стенду (022, 023, 048, 073, 147 — светлая рамка, рисунок до края), карта МИР продакта.

**Столы: 3** — белый, дерево, тёмный или пёстрый (клетчатая скатерть, узор).

**Свет: 3** — дневной, тёплая лампа вечером, тусклая комната.

**Движения** (каждое — отдельная запись 5–20 с; первые 2 с карта уже в кадре, телефон почти неподвижен):

| код | что делать | что проверяет |
|---|---|---|
| `approach` | с 45 см медленно приблизить до 25 см (2–3 с), подержать, отдалить | масштаб кота, дрейф при приближении |
| `tilt` | на ~28 см наклонять телефон над картой от 20° (почти сверху) до 70° (почти сбоку) и обратно | дрейф при наклоне (это облёт — телефон сдвигается) |
| `orbit` | обойти карту по дуге на ~30 см (60–90° по кругу) | дрейф при сдвиге телефона |
| `shake` | 1–2 с быстро потрясти телефон (±10°), потом держать | задержка камеры, срыв ведения |
| `finger` | положить палец на знак Сбера на 2–3 с, потом на угол карты | перекрытие |
| `half` | увести карту наполовину за край кадра на 2–3 с и вернуть | частичная видимость, потеря и восстановление |
| `play` | 1–2 мин «играть»: как ребёнок, всё вперемешку, уводить камеру и возвращать | потери на 5 мин, пересадки |

Минимальный набор на дизайн: `approach`, `tilt` на всех трёх столах при дневном свете + `tilt` при лампе и при
тусклом свете (5 записей). Полный — 3 × 3 × 6 движений. `play` — по 2–3 записи на 3–4 дизайна.

**Негативы: 10** — карты других банков (обязательно зелёные: Тинькофф/«Т», ВТБ, Альфа, МИР без Сбера), книга,
пульт, телефон экраном вверх и вниз, визитка, пачка печенья/коробка, тетрадь. Каждый — 10–15 с с движением `tilt`.

## Классы карт (обязательно в каждом наборе)

| класс | пример имени | что ждём |
|---|---|---|
| Сбер детская | `dkids_white_day_play_1` | посадка ≤ 3 с |
| Сбер дебетовая взрослая (цветной дизайн, знак и «СБЕР БАНК») | `ddebit_white_day_tilt_1` | посадка ≤ 3 с |
| Сбер чёрная/премиальная кредитка (тёмный глянец, крупный тиснёный знак без зелёного, «МИР») | `dblack_white_day_tilt_1` | посадка ≤ 3 с — **сейчас не садится** (см. ниже) |
| чужой банк (красная Альфа, «Т», ВТБ, чёрные карты других банков) | `neg_alfa_white_day_1` | 0 посадок, подсказка «карта другого банка» |

Чёрная кредитка Сбера (запись 20.11, 13:04:15–25): знак — кольцо с галочкой в углу, **крупный** (радиус ≈ 0,15 ширины
карты против 0,03–0,06 у обычных дизайнов), обрезан краем карты и **тиснёный в цвет карты** — по яркости его нет, только
рельеф и блик. Проверка знака (verify.ts `logoScore`) ищет небольшое контрастное кольцо и такой знак не видит; отпечатка
этого дизайна в каталоге (designDb) нет — карта узнаётся как «карта» с чипом и отклоняется как «другой банк». Пробный поиск
по краям рельефа на этой записи давал ложные срабатывания на буквах «СБЕР» (запись экрана к тому же с оранжевым пунктиром
приложения по краю карты), поэтому в код не пошёл. **Нужны эталоны** (режим `?rec`, номер закрыт наклейкой):
- чёрная кредитка Сбера: 3 записи по 10 с (`tilt` на белом столе днём, при лампе, в тусклом свете) + 2 фото сверху
  ровно (лицевая сторона целиком, без бликов и с бликом);
- другие тёмные/премиальные дизайны Сбера, какие есть (СберПервый, Прайм, платиновые, металлик) — по 1–2 записи `tilt`;
- негативы того же вида: чёрные карты других банков (Т-Банк Black, Альфа чёрная, ВТБ) — по записи `tilt`.
С ними — отпечаток дизайна в каталог и подбор порогов знака по рельефу на чистых кадрах.

## Сценарии из боевых записей с iPhone 20.11 (запись экрана, в стенд — кусками без интерфейса по краям)

Записи экрана — с котом и интерфейсом поверх камеры, поэтому ошибки в мм по ним завышены (кот закрывает карту); годятся
для сравнения версий и для поиска переворотов/потерь. Сами записи в репозиторий не кладём.

| клип | время записи | что проверяет |
|---|---|---|
| `a_hooligan_flip` | 0:30–1:00 (12:35:05–35) | далёкая карта под наклоном (~25 px в кадре трекера): кот вверх ногами под картой — зеркальная поза |
| `b_hooligan_play` | 1:00–1:50 | телефон вплотную (кот огромный и обрезан), потери и возврат |
| `c_kind_play` | 1:52–2:48 | смена кота, игра, раскраска |
| `d_glitter_reload` | 3:51–4:36 | после перезагрузки страницы: посадка, «Загружаю распознавание…» поверх игры |
| `e_glitter_paint` | 5:15–5:51 | раскраска, «Мой дом» ↔ карта, кот уезжает к краю стола |
| `neg_alfa_red` | вторая запись 0:00–0:16 | чужой банк — 0 посадок |
| `sber_black_credit` | вторая запись 0:17–0:29 | чёрная кредитка Сбера (сейчас — «другой банк») |
| `sber_debit_adult` | вторая запись 0:29–0:40 | взрослая дебетовая Сбера — посадка; затем быстрые повороты телефона («два Хулигана») |

В отчёте стенда — столбец «вверх ногами / переворотов»: доля кадров с котом, у которых нормаль карты смотрит вниз по
экрану (y < −0,25), и число переворотов нормали (> 60° между кадрами рендера).

## Записи с iPhone 23.11 (пилот /mvp, запись экрана)

Две записи экрана (82 с и 36 с). Клипы для стенда — кусками, обрезка камеры как у 20.11
(`eval.json`: `crop` y 0,0625 h 0,8375, `hfov` 70). Записи и кадры в репозиторий не кладём.

| клип | время записи | что проверяет |
|---|---|---|
| `neg_alfa_red_1123` | 1-я, 0:04–0:12 | красная Альфа — 0 посадок |
| `neg_gold_world` | 1-я, 0:12–0:15 | золотая карта другого банка с картой мира (знак — двойное кольцо с точкой) — **кот садился** |
| `neg_metal_grey` | 2-я, 0:00–0:06 | серая металлическая карта (не Сбер) |
| `neg_wallet` | 2-я, 0:12–0:17 | коричневый картхолдер |
| `sber_old_mir` | 2-я, 0:19–0:34 | старый «СБЕРБАНК» (красно-синий, МИР, маленький знак ≈ 0,036 ширины) — посадка |
| `sber_old_mir_return` | 1-я, 0:42–0:56 | тот же после «Мой дом» → «На карту» (кот на записи закрывает карту — для стенда непоказательно) |
| `sber_old_pan` | 2-я, 0:32–0:36 | быстрый сдвиг телефона: кот остаётся у края экрана, карта уезжает |

Что нашли и что сделано (стенд `--worker-ms 45`, `docs/qa/card-eval/2026-11-23-before.md` → `2026-11-23.md`):

1. **Чужая карта за Сбер.** Знак Сбера ищется по форме на 7 px канонической карты; знак-«мишень» другого банка
   (кольцо, внутреннее кольцо, точка) давал ровно 0,81 в каждом кадре — два «попадания» ≥ 0,6, «Сбер». По форме на
   этом разрешении их не различить (проверяли разрыв кольца, внутреннюю окружность, асимметрию галочки — у старого
   «СБЕРБАНКа» те же цифры). Сделано: (а) «Сбер» по знаку — только если в окне был хотя бы один уверенный кадр
   (`HIT.strong` ≥ 0,9; у Сбера в резком кадре 1,0); (б) отпечатки известных чужих карт (`foreignDb.ts`, генератор
   `tests/card/foreigndb.gen.test.ts`): золотая с картой мира, красная Альфа (2 записи), серая металлическая —
   совпал отпечаток → знак в кадре не засчитывается, 2 кадра — «карта другого банка», посадки «по форме» нет. Порог
   записи — лучшая похожесть на карты Сбера (75 дизайнов каталога в сценах + кадры Сбера с записей) + 0,1.
   `neg_gold_world`: ложных посадок 1 → 0; остальные негативы — 0.
2. **Старый «СБЕРБАНК» не сразу.** На мелкой карте (кадр детектора, 60–110 px, без фрагмента в большем
   разрешении) знак 2–4 px — «0», и такие кадры голосовали «нет знака», разбавляя окно (на `sber_old_pan` знак 0 на
   80 px и 1,0 на фрагменте 165 px). Теперь промах на карте < 110 px не голосует (находки — голосуют). Поиск знака —
   от 0,026 ширины карты (было 0,031), точная проверка — ещё и по фрагменту в полном разрешении, если карта там крупнее
   260 px. Синтетика: маленький знак 0,027 ширины находится в 16 из 24 кадров (было 13). Посадка:
   `sber_debit_adult` 6,0 → 5,3 с, `sber_old_pan` 0,82 → 1,12 с (без потерь), `sber_old_mir` 1,27 → 1,32 с.
3. **«Два кота».** На последних кадрах второй записи кот один: после резкого сдвига телефона он стоит у правого
   края, а карта — слева без кота. Второго экземпляра нет (дом кота не создаёт нового, гироскоп 543601a не
   переключался). Причина — удержание: ведение ушло на поверхность стола, позы отбрасывались (ошибка 5–7 px), а полный
   поиск после посадки шёл редко — карта, снова резкая в кадре, находилась через 1–1,5 с. Теперь при потере > 0,3 с
   полный поиск — через кадр и сразу поиск той же карты по содержимому (`pipeline.ts`, `RELOC_MS`).
   `sber_old_pan`: потерь 1 → 0, ошибка p90 13,8 → 4,4 мм.
4. **После дома.** «Ой, карта пропала! Это не по сценарию» говорилось через 1,5 с после «На карту», пока карта в
   кадре ещё проверялась — теперь «где карта?» ждёт, пока карта в кадре и проверяется (`Tracker.cardInView`, до 8 с).
   Белый экран: вспышка портала (белый центр) гасла над ещё пустым `<video>` — исправлено параллельно в 87c687f
   (заливка тёмно-зелёная и держится до кадра камеры, ≤ 1,5 с). Блёстка «падала» набок: один кадр ведения потоком/по поверхности
   повернул нормаль карты на 28° вбок, дальше позы отбрасывались и кот так и стоял — теперь поворот > 11° из таких
   кадров — только по 3 согласным подряд (как скачок). «Эй-эй, я же падаю!» — это реплика потери карты, не наклона.
   Стенд: `e_glitter_paint` ошибка p90 10,0 → 2,8 мм, дрожание 4,2 → 1,2 мм; `b_hooligan_play` 25,4 → 6,0 мм.

Синтетика (`--synth`) без изменений, кроме `synth_combo`: посадка 0,65 → 1,05 с (уверенный кадр знака).
`d_glitter_reload` теперь садится (раньше — нет), поэтому «восстановление макс.» в сводке — его 15,7 с (кот на записи
закрывает карту).

**Что проверить на iPhone:** золотая/металлическая/чужие карты — кот не садится, подсказка «карта другого банка»;
старый «СБЕРБАНК» и детская SberKids с 30–40 см — посадка ≤ 3 с; «Мой дом» → «На карту» с картой в кадре — без
«карта пропала» и без белой вспышки; резкий сдвиг телефона вбок и обратно — кот возвращается на карту ≤ 1 с; кот не
кренится набок, когда карту закрыли рукой. Для дообучения нужны чистые записи `?rec` чужих карт (золотые,
металлические, чёрные) — отпечатков чужих карт сейчас 4.

## Как выложить на сервер

Сырые записи (даже с наклейкой) в git **не кладём**: папка записей — вне репозитория.

```bash
# на Mac: проверить и размыть номер ещё раз (лист кадров — глазами)
npm run card:blur -- ~/Downloads/d011_wood_day_tilt_1_20261119-101500.mp4 out/d011_wood_day_tilt_1.mp4 --preview
# сайдкар .json копируется рядом сам; затем на сервер
scp out/d011_wood_day_tilt_1.{mp4,json} server:/srv/ar-extra/card-rec/2026-11-19/
```

Если запись сделана не через `?rec` (камера телефона, запись экрана), рядом можно положить `eval.json` с обрезкой
области камеры, углом обзора и масками (формат — `tests/card/eval/clip.ts`), разметку углов `ИМЯ.gt.json` — по желанию.

## Прогон

```bash
npm run card:eval -- /srv/ar-extra/card-rec/2026-11-19            # отчёт в docs/qa/card-eval/<дата>.md + .json
npm run card:eval -- /srv/ar-extra/card-rec --baseline docs/qa/card-eval/2026-11-18.json   # регрессия: код выхода 1
npm run card:eval -- --synth                                         # синтетика с истинными углами (без записей)
```

В отчёт идут только цифры и имена файлов; кадры записей — нет.

Время воркера по умолчанию — мс этого компьютера × 2,5: на занятой машине (параллельные прогоны) цифры гуляют.
Для сравнения версий — `--worker-ms 45` (одинаковая задержка воркера).
