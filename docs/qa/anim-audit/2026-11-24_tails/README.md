## 1. Танец Хулигана «скользит» — исправлено

- Причина: клип Tripo `dance_01` (23 с) секундами шаркает стопой по полу — стопа низко и не отрывается, а клип ведёт её
  на 15–20 мм. Опора лап (footPin) держит только среднее по обеим стопам; IK ноги к точке опоры такой клип не лечит
  (пробовал: 19,8 → 16,7 мм и рывок стопы 19,6 рад/с).
- Сравнил все свободные танцы библиотеки на Хулигане (`clip_*`, подменой действия): dance_04 — 15 мм, **dance_05 — 5,6 мм**,
  dance_06 — 5,7 мм (но опускает голову, морды не видно — лист `hooligan_dance_06_rejected.png`), Meshy dance_kind — 8,3,
  dance_glitter — 6,8 (кружения, не характер Хулигана). Выбран **dance_05** (кулаки, «бокс-грув», лист `hooligan_dance_05.png`):
  `tripoAlias.ts` — `dance_05 → dance_hooligan`.
- Плюс IK ноги для стоящей стопы в танце Хулигана (`GlbCharacter.stepLegIK`: бедро–колено–стопа к точке опоры, полюс —
  колено клипа, стопа в мире как в клипе, ≤ 0,08 роста, вход/выход 0,12 с): 5,6 → 3,1 мм.
  **Только Хулиган**: у Добряка (Meshy dance_kind) IK давал рывки бедра/стопы 48–53 рад/с, у Блёстки (кружения на носке) —
  лапы 8 → 11 мм; у них как было.
- Стенд, Танец Хулигана: **плохо (лапы 19,8) → ok (лапы ≤ 4,7, щелчок ≤ 9,8)**; «Фирменное → Танец»: лапы 14 → 8,4.

## 2. Плечо с предметом в шарфе/наушниках (6–7 мм) — НЕ исправлено, причина найдена

Ячейки: Угостить (Хулиган, Добряк), Какао, покой Добряка (кружка в покое), «Фирменное → …», «Угостить → Обнять».
Что проверено на стенде (Хулиган + Добряк, Угостить + Какао, по 3–6 мин на вариант):

| вариант | проникновение |
|---|---|
| как есть | 6,2–7,5 мм в 60–75 % кадров |
| подбор полюса локтя (13 углов вокруг оси плечо→цель, глубина шаров лапы в прокси) | 6,2–7,4 — без изменений |
| полюс вниз-вперёд / вниз / назад | 5,5–7,1 |
| ключица: подача ≤ 0,15 рад; вниз ±0,3 рад; вперёд 0,5–0,9 рад | 6,3–7,3 |
| предмет дальше вперёд и ниже (z +0,04…0,06, y −0,02…−0,04) | 4,6–7,1 |
| **коллайдер на лапе с предметом (без исключения)** | **0–0,2 мм**, но кружка/рыбка не доходят до рта — у груди (листы `*_collider_on_rejected.png`) |

Причина: лапа коротка — в 55–75 % кадров `reachAssist` вытягивает её в струну (растяжка > 1), прямая «плечо → рот»
проходит внутри кольца шарфа/дуги наушников у плеча. Полюс локтя у прямой лапы ничего не меняет, а всё, что выводит лапу
из кольца, уводит предмет ото рта. На листах крупно (`hooligan_treat_focus.png`, `kind_cocoa_focus.png`) рукав идёт поверх
шарфа/чашки наушников, место проникновения закрыто лапой с камеры сверху-спереди. Код проб откатан, в коммит не вошёл.

Что поможет (решение продакта): (а) клип Meshy «пьёт/ест, держа предмет ниже, голова наклоняется к нему» — прежние
hold_*_body были хуже процедурных; ar-auto сейчас завис, генерацию не ставил; (б) шарф/дуга наушников с весами плеча в
модели (меш одежды подаётся вместе с плечом) — правка моделей Хулигана и Добряка; (в) принять как есть.
