# Плечо с предметом в шарфе / наушниках — 24.11.2026

Продолжение [2026-11-24_tails](../2026-11-24_tails/README.md) п. 2: лапа с предметом у рта (рыбка, кружка) шла сквозь
шарф Добряка и дугу наушников Хулигана на 6–7 мм. Продакт одобрил оба варианта — сделаны оба.

## Что сделано

**A. Клипы Meshy «предмет у груди, голова к нему»** (ar-auto `meshy-hold-low-2411`, **52 кредита**, 4 клипа, prime):
`hold_treat_low`, `hold_treat_low_b`, `hold_sip_low`, `hold_sip_low_b` (`scripts/models/t2m_prompts_v2.json`).

- Подключён `hold_treat_low` — «Угостить» у Хулигана и Добряка (`glbCharacter.ACT_BODY_LOW`). Клип кланяется
  слишком глубоко (сверху морды не видно ~1 с), поэтому корпус/шея/голова берут 35 % поклона клипа
  (`HOLD_LOW_BOW`); голова наклоняется к рыбке, рыбка у рта (листы).
- Лапа с предметом при этом теле — под коррекцией BodyCollider на 15 % (`HOLD_LOW_PUSH`; было — исключена целиком):
  выводит плечо из кольца, промах предмета от цели ≤ 2,4 мм (Хулиган) / ≤ 4 мм (Добряк). 50 % — уже 8–15 мм.
- `hold_sip_low` (+ `_b`) **не подключены** (`PILOT_MESHY_OFF`): кот складывается над кружкой — морды не видно даже при
  20 % поклона, кружка у груди. Какао — процедурное тело + коррекция 15 % (`HOLD_PUSH.cocoa`).
- `hold_treat_low_b` — не лучше основного (выключен). Блёстка — без изменений (тело Угостить как было).

**B. Шарф / дуга наушников со скином плеча** (`scripts/models/shoulder_skin.py`, без Blender — только веса скина):

- Выяснилось: у Tripo-рига ткань у плеч уже на 40–70 % шла за ключицей и на 25–50 % — за головой, а прокси
  столкновений — только за `Neck`. Прокси p1 теперь со скином: `blend` в `public/models/v2/{hooligan,kind}_p1_colliders.json`
  (`colliders.py` — средние веса вершин детали у капсулы; `bodyCollide.updateBlend` — линейный скин).
- Веса: Head → Neck у ткани (кроме вершин морды), ключица → плечо у плечевого сустава (радиус 0,16 / 0,22 роста).
- p2 пересобран `face_rig.py` из нового p1: позиции и все морфы int16 — байт в байт как были.
