## Осталось

1. **Плечо/предплечье с предметом в дуге наушников (Хулиган) и шарфе (Добряк)** — Угостить, Какао, «Фирменное →
   Погладить», покой Добряка с какао: 5,7–7,5 мм в 40–75 % кадров. Разворот локтя (п.2) нашёл лучшее положение, но при
   кружке/рыбке у рта предплечье всё равно проходит через раздутые прокси шарфа/дуги (см. PROPS_ALIVE: на листах почти
   не видно). Дальше — цели IK far/near для этих котов или тоньше прокси шарфа и дуги. Цель ≤ 2 мм не достигнута.
2. **Кровать**: «лёжа в опоре −20 мм» — метрика в системе кота, а сцена кровати кладёт кота креном −π/2 (это не матрас).
   По листам после правки тело на матрасе, морда к зрителю, пачка не торчит. Нужна метрика по миру/матрасу.
3. **Скольжение лап** в Танце (7–19 мм), раскраске (лапы 16–22 мм, ходьба опорой walk ~100 мм по метрике «от точки
   постановки»), «8 кнопок», «Кровать → кнопка» — клипы сами переступают; ≤ 5 мм достигнуто только в части idle.
4. **Смена кота** на устройстве: первый кадр нового кота 49–91 мс при ЦП ×4 (первый apply коллайдера + update). Стенд с
   виртуальным временем не показывает отрезки подготовки клипов (паузы MessageChannel не двигают его часы).
5. **Блёстка**: в Зеркальце лапа у банта теперь под коррекцией — не в голове, но ладонь чуть отходит от банта (лист
   `glitter_sig_mirror_after`, 2,5–3 с). Живой слой сам даёт дрожь рук p95 4–10° (так же и при `?collide=0`) — это
   aliveIdle, отдельная задача.

## Как прогнать

Локально (2 ядра — ≈ 20–25 мин на кота):

```
node scripts/qa/anim-audit/audit.mjs --tag after                       # сборка pilot + все коты, листы
node scripts/qa/anim-audit/audit-report.mjs after                      # summary_after.json
node scripts/qa/anim-audit/table.mjs after before [perf4]              # table_after.md (было → стало), idle_after.md
node scripts/qa/anim-audit/compare.mjs before after                    # пик ω, щелчок, лапы, проникн., пол, дрожь — по сценариям
node scripts/qa/anim-audit/audit.mjs --no-build --tag d1 --cats glitter --only rest,sig_mirror --no-sheets \
  --trace "app.character.collider.exemptW.Left"                        # своё значение в кадр
node scripts/qa/anim-audit/spikes.cjs d1 glitter/sig_mirror [--all --from 2000 --to 2600]
```

Выход — `bench-out/anim-audit/` (raw/, sheets/, summary_*.json, table_*.md); «до» этого аудита — `raw/before.json`
(сырые кадры в репо не кладём — 19 МБ; сводки — `data/`).

**На сервере swe с клипами Meshy** (`/srv/ar-extra/models/anims/meshy`: манифест 109, в том числе 10 новых —
hold_sip_body, hold_treat_body, hold_mirror_body, skate_hop_on/cruise/ollie_air/hop_off, idle_glitter_alive,
glitter_react_coy/happy; локально их нет). Стенду нужны node ≥ 20, git, Chrome (headless, рендер swiftshader) и
системные библиотеки Chrome; ветки `server-out` нет (ar-auto не установлен), а его очередь принимает только
meshy/tripo/eleven — поэтому вручную, один раз (Debian/Ubuntu, под обычным пользователем; ≈ 1–1,5 ч на два прогона):

```bash
sudo apt-get install -y git fonts-dejavu-core libnss3 libatk1.0-0 libatk-bridge2.0-0 libcups2 libdrm2 libxkbcommon0 \
  libxcomposite1 libxdamage1 libxfixes3 libxrandr2 libgbm1 libasound2 libpango-1.0-0 libcairo2
git clone https://github.com/vsershov21-spec/ar.git ~/ar-qa && cd ~/ar-qa && npm ci
npx @puppeteer/browsers install chrome@stable --path ~/.cache/ar-qa-chrome
export CHROME=$(ls -d ~/.cache/ar-qa-chrome/chrome/linux-*/chrome-linux64/chrome | tail -1)
nohup bash -c '
  node scripts/qa/anim-audit/audit.mjs --tag srv_base --no-sheets &&
  node scripts/qa/anim-audit/audit.mjs --no-build --tag srv_meshy --meshy /srv/ar-extra/models/anims/meshy &&
  node scripts/qa/anim-audit/audit-report.mjs srv_base && node scripts/qa/anim-audit/audit-report.mjs srv_meshy &&
  node scripts/qa/anim-audit/table.mjs srv_meshy srv_base' > ~/ar-qa/anim-audit.log 2>&1 &
```

(на Ubuntu 24.04 пакет звука — `libasound2t64`). Результат: `~/ar-qa/bench-out/anim-audit/table_srv_meshy.md` (опоры →
клипы Meshy, по ячейкам), `idle_srv_meshy.md`, листы `bench-out/anim-audit/sheets/`, в начале лога — «Meshy: загружено N,
нет M, отвергнуто K» с причинами. Следующие разы: `cd ~/ar-qa && git pull && npm ci`, `export CHROME=…` и тот же `nohup`.
Принести сюда: `table_srv_meshy.md`, `summary_srv_meshy.json`, лог и несколько листов — их можно закоммитить в
`docs/qa/anim-audit/server/`.
