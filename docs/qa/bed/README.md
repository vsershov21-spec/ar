# Кровать: поза лёжа по матрасу — до / после (23.11)

Жалоба: «кот ложится спать криво на кровать». Стенд — `scripts/qa/bed-stand.mjs` (пилотная сборка, коты v2/p1, клипы
Meshy из `server-out:out/latest/meshy`, виртуальные 30 к/с, `?flow=home&zone=bedroom&hour=14` → «Уложить спать» →
сон → два тапа (ворочается) → «Разбудить»). Листы: сверху — камера пилота, ниже — вид сверху (изголовье вверху), под
кадром — метрики **в системе матраса** (`BedProp.mattress`), не кота.

- `before_<кот>.png` — origin/main 5bb7f3c; `after_<кот>.png` — эта ветка; сырые метрики — `before.json`, `after.json`.

## Причина

1. **Клипы Meshy кладут тело в своей системе, а сцена ставила их «как ТЗ»** (`REAL_LIE`: yaw 0 — «голова вправо»).
   У `sleep_loop_bed` ось таз→шея в системе якоря смотрит в стену (−Z), у `lie_down_side` — ещё на 150° иначе. Итог:
   кот спал **поперёк кровати** (ось 92–94° к длинной оси), голова мимо подушки (Δz −36…−43 см), тело в матрасе на
   8–20 см (Хулиган, Блёстка: 17–28 % вершин тела ниже простыни; глубина плавала от прогона к прогону — интегратор),
   одеяло накрывало 7–22 % тела — висело «стеной» рядом.
2. Подгонка позы `fitPose` — интегратор (подъём/наклон/сдвиги копились и не сбрасывались между сессиями и котами),
   поворот вокруг вертикали не правила вовсе; наклон считала по `Neck.x − Hips.x > 0`, а у Meshy это условие ложно.
3. Одеяло ложилось по капсулам костей; у кота на боку туловище в худи толще капсул — торчало сквозь ткань.
4. Подушка 14 см: у котов с большой головой (Добряк) тело висело над простынёй на 5–7 см.

Крен опоры `INTENDED_LOW`, смещение `zoneSpot` и масштаб кота к кровати — не причина (ground clamp для поз сна уже
работает; точка сна и масштаб одинаковы у всех котов, разница v2/p1 — только в толщине головы/одежды, её учитывает замер).

## Что сделано (src/home/bedFlow.ts, bedProp.ts)

- **Выравнивание по матрасу** (`alignTick`/`measure`): из позы текущего клипа в системе якоря (кости + вершины кожи)
  считается поза якоря — ось тела вдоль кровати головой к изголовью, спина горизонтально (наклон ≤ 0,25 рад, чтобы голова
  легла на подушку), центр вершин головы — на середину подушки, тело — по центру матраса по ширине, нижняя вершина тела —
  на простыне, голова — в подушке не глубже 5–8 см. Геометрия — `BedProp.mattress` (как построены матрас и подушка).
  Не интегратор: цель на клип (кот → клип → поза) запоминается; смена клипа (лёг → петля сна → ворочается → потягивается)
  первые 0,7 с меряется каждый кадр без сглаживания — тело остаётся вдоль кровати, пока микшер смешивает позы.
  Мерим только клипы лёжа (во время шага может заиграть `talk_*` реплики).
- **Одеяло по телу** (доработка 23.11, вторая итерация): силуэт — вершины кожи и прядей меха (BD_FurCards: хвост и
  пряди больше не просвечивают) без головы и лап, ткань — 1,8 + 1,2 см над вершиной; от тела ткань спадает к матрасу
  конусом (наклон 0,8, без вертикальных стенок), по краям матраса свисает вниз; купол «горба» над телом убран (он и давал
  «шатёр» 10–20 см с гребнем). Край у шеи и сгиб, пока одеяло наезжает/откидывается, спускаются к матрасу плавно (22 см,
  smoothstep). Лапы — поверх одеяла (поднятая к мордочке лапа ставила ткань гребнем). Во время «ворочается» силуэт не
  обновляется, а высоту тела alignTick держит на матрасе (клип поднимал его на 5–7 см и ткань тянулась вверх).
- **Подушка ниже** (0,13 → 0,09 м, наклон 0,12 → 0,08 рад).
- Стенд `scripts/qa/bed-stand.mjs` + метрики по матрасу.

## Сон (5 с после «Уложить спать»)

ось — угол таз→шея к длинной оси кровати; спина — наклон; низ — нижняя вершина тела над простынёй (мм комнаты, рост кота
≈ 1,1); в матр. — доля вершин тела ниже простыни; голова Δx/Δz — центр головы от центра подушки; одеяло — доля вершин
туловища и ног под тканью (лапы — поверх одеяла по замыслу); сквозь — над тканью (допуск 1 см).
«До» по одеялу мерилось прежним стендом (всё тело с лапами, допуск 4 мм) — сравнивать по листам.

| кот | ось | спина | низ, мм | в матр. | голова Δx / Δz, мм | на подушке | одеяло | сквозь | юбка, мм |
|---|---|---|---|---|---|---|---|---|---|
| Хулиган | 93° → **0°** | −5° → 6° | −203 → **−1** | 28 % → **0** | 7 / −434 → **−8 / 15** | нет → **да** | 7 % → **83 %** | 4 % → 17 % | — |
| Добряк | 92° → **0°** | −4° → 10° | −81 → **6** | 1 % → **0** | 26 / −359 → **−7 / 54** | поперёк → **да** | 22 % → **93 %** | 14 % → **7 %** | — |
| Блёстка | 94° → **0°** | −6° → 7° | −135 → **3** | 17 % → **0** | 32 / −395 → **−2 / 52** | нет → **да** | 19 % → **98 %** | 13 % → **2 %** | −64 → **3** |

«Сквозь» у Хулигана 17 % — край худи у шеи, где ткань спускается к матрасу (с камеры пилота не видно).
Камера пилота (верхний ряд листов): одеяло — мягкий холм по телу, свисает по переднему краю матраса, без стенок и гребня;
у шеи и на сгибе (укрывается / откидывается) ткань спускается плавно; кед и хвост не торчат.

Остаётся: в «ворочается» (`turn_over_sleep`, 1,4 с) клип двигает лапы и корпус — силуэт одеяла на это время замирает,
так что по стенду до 56 % туловища на мгновение над тканью (с камеры пилота — лапы и плечо выше края). У Блёстки на
сгибе, пока одеяло наезжает/откидывается (≈ 1 с), виден край юбки.

## Как прогнать

```
git archive origin/server-out out/latest/meshy | tar -x -C /tmp/bedmeshy
VITE_EDITION=pilot npx vite build --outDir /tmp/bedstand/dist
node scripts/qa/bed-stand.mjs --dist /tmp/bedstand/dist --meshy /tmp/bedmeshy/out/latest/meshy --tag after [--cats kind] [--morning]
```
