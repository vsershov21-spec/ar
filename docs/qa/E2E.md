# E2E пилота `/mvp` — `npm run e2e:pilot`

Сквозной набор для пилота (редакция `pilot`, https://ar.vershov.com/mvp): headless Chrome как iPhone (390×844, UA iOS,
касания), фейковая камера с синтетической картой Сбера на столе, фейковый микрофон (тихая комната). Каждый сценарий —
отдельный тест; провал — снимок и лог режиссёра в `bench-out/e2e/<сценарий>.png|.log.txt`, итог — `bench-out/e2e/report.json`.

## Как запускать

```bash
npm run e2e:pilot                         # сборка pilot (dist/mvp) + все сценарии, ~17 мин
npm run e2e:pilot -- --no-build           # без сборки (dist/mvp уже собран)
npm run e2e:pilot -- --no-build --only 03,05_home   # только сценарии с такими префиксами/подстроками
npm run e2e:pilot -- --headful            # с окном
```

Код: `scripts/qa/e2e/run.mjs` (прогон), `lib.mjs` (сервер, браузер, «телефон», жесты), `tests.mjs` (сценарии).
Нужны `/usr/bin/google-chrome` (или `CHROME=…`) и python3 (видео карты делает `scripts/bench/gen_card_video.py`,
один раз — `bench-out/qa/media/still.y4m`, общий с QA-стендом).

Как устроен стенд:

- **сборка** — `AR_EDITIONS=pilot scripts/build/editions.mjs` → `dist/mvp`; ассеты — из `public/`, сжатые модели —
  из `.cache/model-opt` (как `scripts/qa/quick-speed.mjs`);
- **озвучка** — `scripts/scenario/fake-voice.mjs`: тишина длиной как реплика, набор «озвученного» — `voice-src/el_batch_all.jsonl`
  (строгий режим «только озвученные реплики», как на сайте); звук в headless не слышен, реплики проверяются по событиям
  `speak` / пузырю;
- **сервер** — свой http: `/api/progress/*` — мок (пустой документ, запись — новая версия), каждый запрос с телом
  запоминается: по ним сценарий 8 проверяет воронку и что имя ребёнка не уходит; 404 собираются (сценарий 10);
- **страница** — прелюдия QA-стенда `scripts/qa/page-prelude.js` (ускорение времени `__qaSetK`, ловушки `error` /
  `unhandledrejection`), рендер — заглушка (`qaInstall('stub')`: SwiftShader рисует кадр кота сотни мс; снимки — по-настоящему);
- **голос** — модели Vosk (`public/models/vosk-ru-small`) в репозитории нет: на стенде распознавание недоступно, это
  и есть путь «голос недоступен → поле имени и кнопки»;
- **согласие** — режим (`config/consent.ts`) задаёт сборка и меняет только разметку заставки; `/mvp/?consent=checkbox|parent`
  сервер стенда отдаёт с той же разметкой, что сделала бы сборка с `VITE_CONSENT_MODE` (тексты — из `consent.ts`);
- **нажатия** — настоящими касаниями (`touchscreen`), если кнопка видна (колонки «как у Тома», ряд комнаты, чипы,
  стрелки, док); пункт, который сейчас спрятан (колонки уехали к краю), — тем же путём, что тап по кнопке каталога
  (`app.runCatalogItem`); в отчёте сценария 3 у каждого действия помечено `tap` / `run`.

## Результат (22.11, `e2e-pilot` поверх origin/main 8001f47)

**16/16 зелёных + 10_no_404** (~17 мин; стенд — 2 ядра, параллельно шёл аудит анимаций; повтор после rebase на cc03525 — тоже зелёный).
Длинная сессия: куча JS 15 → 16 МБ, геометрии 21 → 21, текстуры 26 → 26, программы 29 → 29, AudioBuffer 28 → 27,
AnimationMixer живых 1 → 1 (активных 1 → 1), DOM 488 → 487; кадры/с (рендер-заглушка) 27–46, без падения.

Найдено и исправлено (каждое — отдельный коммит):

1. **Дом → «На карту»: карта не находилась (через раз).** Кадр, отправленный в воркер трекера перед «Мой дом»,
   не возвращался (воркер убит), флаг `busy` оставался — новый воркер не получал ни одного кадра, кот: «Алё, а карта где?»
   и звал домой. `cardTracker.stop()/start()` сбрасывают `busy`.
2. **Микрофон запрещён — кот всё равно звал «Скажи…», тоста не было.** Запрет, полученный в общем запросе
   камера+микрофон (заставка быстрого входа), забывался: `MicInput` считал микрофон доступным. Теперь `MicInput.markDenied`
   (тост «Нет доступа к микрофону — жми кнопки», `voiceIn().mic = false`); подсказка «нажми сюда» не показывает
   на микрофон, когда голос недоступен; из вариантов реплик выбираются те, что не зовут говорить («Скажи „да“»), и —
   в пилоте без повторялки — те, что не зовут в неё («Скажи „повторяй за мной“»).
3. **Тост закрывал чипы.** «Нет доступа к микрофону» / «Голос пока не работает» 5 с перехватывали касания —
   «Давай!» / «Не надо» не нажимались. `.toast { pointer-events: none }`.
4. **Туман пальцем не включался.** С трекером карты любое долгое нажатие открывало меню «Пересадить на другую карту».
   Меню — только на коте или на карте, мимо них — туман.
5. **Скейт увозил Хулигана за край экрана** (карта у края кадра): после проезда кот стоял за правым краем.
   Точки дуги проезда подтягиваются, чтобы ноги кота оставались на экране (режиссёр, `skateArc`; клипы скейта не тронуты).

Агенту анимаций (не правилось — `src/character/**`):

- `hitZone` (зона касания) шире силуэта: у Добряка (центр головы x≈280, `rawCatRect`) точка (110, 140) — зона `head`
  (`app.zoneAt`) — долгое нажатие рядом с головой считается «на коте» (туман не включается, меню «Пересадить»).
- У фирменных `skate` / `cocoa` / `mirror` клип в записи стенда — `idle_breathe` (тело ведёт шаблон `runAct`), реплик у
  этих событий нет — кот выполняет их молча (проверить, так ли задумано).

Мелочи, без правки: стрелки комнат дома первые ~250 мс стоят посередине края экрана и потом прыгают вниз (первый такт меню);
`page_open.ms` — время старта бандла, а не открытия страницы (в воронке позже `splash_shown`); на стенде (2 ядра под
нагрузкой) камера после нажатия — от 0,5 до 16 с, `quick-speed.mjs` в тех же условиях — 1,8 с: это загрузка стенда, не регресс.

## Что headless не покрывает — проверить на iPhone

- настоящие окна разрешений Safari (камера+микрофон одним окном; запрет только микрофона; «Попробовать ещё раз» после
  запрета в настройках сайта) и тост про микрофон;
- звук: голос ElevenLabs, синхронность пузыря и голоса, громкость с эхоподавлением, переключатель «Без звука»;
- распознавание Vosk (модель 45 МБ, первое «скажи»), «Давай!» / «Не надо» голосом;
- реальная карта: поиск при бликах, посадка, пересадка долгим нажатием на карту, туман долгим нажатием мимо карты;
- скейт Хулигана на реальной карте по центру кадра — не уезжает ли за край, в какую сторону едет;
- «На карту» из дома несколько раз подряд (индикатор камеры iOS, карта находится сразу);
- производительность (FPS, нагрев) — на стенде рендер-заглушка;
- СберKids: диплинк пока плейсхолдер (`config/sberkids.ts` TODO) — открывается веб-страница RuStore;
- заставка на медленной сети оператора, `prefers-reduced-motion`, поворот экрана, вырез и safe-area.
