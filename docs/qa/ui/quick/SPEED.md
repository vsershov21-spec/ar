# Быстрый вход (`intro.quick`): скорость до/после

Стенд: `scripts/qa/quick-speed.mjs` — headless Chrome, iPhone-вьюпорт 390×844, холодный кэш (новый профиль на прогон),
сеть — пресеты DevTools **Slow 4G** (562,5 мс, ~180 КБ/с) и Fast 4G (165 мс, ~1,1 МБ/с), gzip для текста как на проде,
CPU без замедления, разрешения даются сразу, на «камере» — карта Сбера (`still.y4m` QA-стенда).
«До» — пилот `/mvp` на `origin/main` 33d80c3 (онбординг 4 экрана), «после» — эта ветка. Время — от начала навигации.
Сценарии: «сразу» — жмём, как только можно; «прочитал» — смотрит на экран 4 с, потом жмёт.
Старый вход до готовности приложения на «Открыть камеру» не реагировал — стенд жмёт повторно раз в 1,5 с (отсюда 25–27 касаний).

## Что ещё ускорит кота (сделано 22.11 — см. ниже «Лёгкий кот»)
- `anims_v1.glb` отдаётся без сжатия: gzip даёт 1,2 МБ вместо 2,2 МБ (−5 с на Slow 4G); проверить `encode zstd gzip`
  в Caddy для `.glb/.json/.wasm`, либо сжать клипы (meshopt/квантование) в `model-opt`.
- Лёгкий первый LOD кота для пробуждения (текстуры 512², ~0,5 МБ) и подмена на полный после — кот на карте за секунды.
- Модель и движения можно начинать качать прямо из `index.html` (preload по карте `__MODEL_OPT__`), а не после main.js:
  ещё −3…5 с; но на медленной сети это отнимает полосу у кода трекера (камера позже) — решать по данным пилота
  (`camera_granted.ms`, `card_found.ms`, `cat_awake.ms` в воронке).

Повторить: `AR_EDITIONS=pilot node scripts/build/editions.mjs && node scripts/qa/quick-speed.mjs dist after --runs 2`
(«до» — копия `dist/mvp` со старого коммита: `node scripts/qa/quick-speed.mjs <папка> before`), `--net fast4g`, `--timeline`.

# Лёгкий кот: движения пакетами, текстуры 1K, поиск карты параллельно (22.11)

«До» — `origin/main` 4b4844c (быстрый вход), «после» — эта ветка. Стенд тот же (`scripts/qa/quick-speed.mjs`, холодный
кэш, iPhone 390×844, swiftshader), сценарий «сразу», по 2 прогона. Новые столбцы стенда:
**карта** — карта нашлась; **пробуждение** — кот скачан и разобран, карта найдена, сцена «из карты» пошла;
**кот** — кот вылетел из карты (`stage.intro.scale > 0`), два кадра подряд.
«После, сервер как сейчас» — Caddy жмёт только текст/js/wasm (`.glb` — как есть); «после + Caddy» — `--encode all`,
как будет после `scripts/deploy/caddy-encode.sh`.

**Движения** (`scripts/build/anim-pack.mjs`, при сборке, исходник `public/models/anims_v1.glb` не меняется):
только повороты костей и высота таза; ключи прорежены с допуском 0,5° на сустав / 1 мм на кота ростом 1 м (как
упаковка клипов Meshy), кватернионы нормируются перед сравнением (int16 «шумит» до 0,5°); общие ключи времени — один
accessor; meshopt с фильтром QUATERNION 16 бит. Ключей 262 133 → 86 229. Чтобы `animPrep` готовил клипы как раньше,
в extras клипа — подсказки по исходным кривым: шум (σ сглаживания) и границы обрезки неподвижного начала/конца; порядок
в библиотеке (`libIndex`: от него зависит, какой пресет Tripo займёт id). Стартовый пакет — `src/character/animPacks.ts`
(START_IDS: покой, пробуждение, знакомство, касания по зонам, глажка, стекло, фирменный двойной тап; по стенду
`scripts/qa/anim-start-probe.mjs`) с замыканием по правилам `GlbCharacter` (своё имя, псевдоним Tripo, исходник
монтажа cut, опора fallback). Остальное — `GlbCharacter.loadDeferred()`: после пробуждения (+1,5 с), сразу при смене
кота на карте, через 30 с без карты, или когда попросили клип, которого ещё нет; регистрация заново в порядке полной
библиотеки (раскладка id та же, что при загрузке целиком: 123 id у обеих сборок), потом клипы Meshy.

Сверка «без визуальных потерь»:

## Сервер: сжатие Caddy

`encode` Caddy по умолчанию жмёт только свои типы (text/*, json, js, wasm, svg…); `.glb` отдаётся как есть, хотя
meshopt рассчитан на gzip поверх (движения −55…65 %, модель −28 %). `scripts/deploy/caddy-encode.sh` (root): в блоке
`ar.vershov.com` прежние `encode` — в комментарий, свой блок `encode { zstd; gzip 6; match Content-Type … }`
(текст + `model/gltf-binary`, `application/octet-stream`, `image/ktx2`, wasm), `caddy validate` → reload; проверки
curl с Accept-Encoding (модель, пакет движений, транскодер, main.js), `/mvp/`, `/lab/`, `/api/progress/health`, Range;
сломалось — откат. Запуск — `docs/DEPLOY.md` («Сжатие ответов»).
