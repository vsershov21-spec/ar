# Мимика v3: рот геометрией и морфы лица (риг p2, 23.11)

Продакт: «проблемы с анимациями открытия рта, мимикой — отредактировать модели и детализировать». Было: рот — плоская
шейдерная накладка MouthD (линия «ω», «полость» и язык нарисованы), челюсть — ключи на всём теле. Стало (только lab,
функция `face.morph`; пилот и MVP — как было, пока продакт не посмотрит):

- **Модели** `public/models/v2/<кот>_p2.glb` = p1 + `scripts/models/face_rig.py` (Blender headless, `pip install bpy==5.3.0`):
  морда отдельным мешем `FaceSkin` (+ мех `BD_FurShellFace`), разрез губ точно по линии рта, тёмная полость `MouthCavity`,
  два верхних клычка `Teeth` (в покое короткие — не видны в щели губ), язык `Tongue`; 26 морфов: виземы Rhubarb
  `vis_A…vis_H` (X — покой), `smile`, `smile_open`, `smirk`, `frown`, `surprise`, `pout`, `tongue_out`, кожа век
  `blink_L/R`, `squint`, `wide`, брови `brow_up/down/angry/sad`, `cheek_up`, `cheeks_gum`, `nose_wrinkle`.
- **Рантайм** `src/character/faceMorphs.ts`: визема (сырая, `LipSync.target`) → `vis_*` с кроссфейдом 75 мс; без виземы —
  амплитудный фолбэк по раскрытию; пресеты/эмоции/моргание → ключи рига (`mapFace`); во время речи открытые формы эмоций
  приглушаются. Сроки и сбросы лица (≤ 8 с, сброс на cancelAct) — прежние (FaceMixer/resetFace), тест `tests/faceMorphs.test.ts`.
- **Сравнение**: `?face=morph` / `?face=shader` (lab; MVP и пилот — только с `?from=test`).

## Проникновения (`face_rig_<кот>.md`, пишет `face_rig.py --report`)

Проверка по видимости: вершина клычков/языка/полости, до которой с одной из 5 камер (анфас, ±30°, ±20° по высоте) луч
доходит мимо кожи (морда в этом ключе + тело) и мимо проёма рта (лента между губами), — торчит сквозь кожу. Плюс перехлёст
губ (нижняя выше верхней) и мех на кромке губ (длина `_FURLEN` у разреза — 0, пряди не лезут в рот).

| кот | вершин наружу (покой + 15 ключей) | перехлёст губ | мех на кромке |
|---|---|---|---|
| Хулиган | 0 | 0 | 0 |
| Добряк | 13 (по 1–2 у кромки губ в B/D/E/F/G/smile_open/surprise — на кадрах не видны) | 0 | 0 |
| Блёстка | 1 (кончик клычка в surprise) | 0 | 0 |

Отдельно: в покое и во всех ключах сборка проверяет, что разрез делит губы целиком (иначе `face_rig.py` падает) — с одним
подразбиением у грубой сетки Tripo верх «протекал» в низ и челюсть тянула кожу занавеской поверх рта.

## Размер и производительность

| кот | GLB p1 → p2 | сжатый (meshopt + KTX2, телефон) | текстура морфов в GPU |
|---|---|---|---|
| Хулиган | 4.58 → 4.83 МБ (+5.6 %) | 2.07 → 1.89 МБ (−8.4 %) | 8.85 → 6.41 МБ |
| Добряк | 4.61 → 4.60 МБ (−0.1 %) | 2.11 → 1.93 МБ (−8.7 %) | 8.84 → 3.58 МБ |
| Блёстка | 4.73 → 4.93 МБ (+4.2 %) | 2.11 → 2.12 МБ (+0.4 %) | 8.59 → 6.96 МБ |

Морфы — только на морде: тело и его мех больше без ключей (в p1 13 ключей на 17–18 тыс. вершин тела и столько же у меха —
морф-цикл в вершинном шейдере на каждую из 6–12 оболочек). В p2 морфят 3.8–7.9 тыс. вершин морды (+ её оболочки),
полость (~0.8–1 тыс.), язык (304), клычки (20), карточки меха (только ключи, что их двигают), усы. Ключи — sparse,
int16 normalized (KHR_mesh_quantization), малые смещения (< 0.006 W Хулигана ≈ 0.9 мм) не пишутся. Буферы тела ужаты
(вершины морды убраны). Сборка (`scripts/build/model-opt.mjs`) раскрывает sparse int16 в плотные — gltf-transform писал
их нулями; нули между ключами meshopt сжимает почти даром (PIPELINE `…-densei16`, кэш моделей пересобирается).

## Что посмотреть на iPhone (lab, или пилот `?from=test&face=morph`)

1. Речь: рот открывается и закрывается в такт, между словами смыкается; нет «дрожи» (кроссфейд 75 мс).
2. Клычки не видны в закрытом рту, видны при «а»/улыбке; язык — при «а», «л», `tongue_out` (дразнилка).
3. Мех у рта: при открытом рте пряди не лезут в полость; на подбородке карточки идут за челюстью.
4. Блёстка — слабое место: рот в складке под нависающими подушечками усов; открытый рот выходит «коробкой», закрытая
   улыбка «ω» видна слабее нарисованной шейдером. Смотреть сверху и снизу: полость не просвечивает сквозь подушечки.
   Возможно, Блёстке оставить шейдерный рот (решение продакта; переключение — по коту, если понадобится).
5. Касания, глажка, действия с предметом (какао, жвачка, «чмок») — лицо как раньше, не залипает (≤ 8 с), сброс на отмене.
6. Производительность: FPS с мехом не ниже p1 (`?face=shader` для сравнения).

Включить в пилоте: `src/config/edition.ts` → `'face.morph': { …, pilot: true }` (и колонка в docs/EDITIONS.md).
