# Тестовые флоу

## MVP и Lab: куда ведут ссылки страницы /test (docs/EDITIONS.md)

Страница `/test` одна (собирается в MVP, `dist/test/`), прототип — в двух редакциях: `https://ar.vershov.com/` (MVP)
и `https://ar.vershov.com/lab/` (Lab). На странице сверху — переключатель **«Lab / MVP»** (по умолчанию Lab, выбор
помнится в `sessionStorage`), каждая ссылка-флоу строится так:

| Переключатель | Ссылка | Пример |
|---|---|---|
| Lab (по умолчанию для новых флоу) | `/lab/?<параметры>` | `/lab/?flow=rps&nocard` |
| MVP | `/?from=test&<параметры>` | `/?from=test&flow=riddle` |

- В MVP отладочные параметры (`?flow`, `&dur`, `&rate`, `&zone`, `?nocard`) работают **только с меткой `from=test`**
  (или при переходе со страницы `/test` — по referrer); без неё MVP вырезает их из адреса. `?anycard`, `?grab=bitmap|frame`,
  `?glb` в MVP не работают вовсе, а флоу новых мини-игр (`emo`, `rps`, `simon`) — тоже: в MVP этих игр нет.
  Такие кнопки при «MVP» бледные с подписью «только Lab» (страница спрашивает `filterSearch` из `src/config/edition.ts`).
- `?debug`, `?fresh`, `?reset=1`, `?char=…`, `?noname`, `?progress=0`, `?perf` работают в обеих редакциях.
- Хранилище у редакций раздельное: в Lab ключи localStorage с префиксом `lab:` и свой id устройства (свой код на
  `/test/admin`). «Очистить память» / «Что помнит кот» и «Сброс по ссылке» работают с выбранной редакцией; блок
  «Сбросить прогресс этого устройства» (код устройства) — с MVP; сброс Lab на сервере — `/lab/?reset=1`.


## Прогресс устройства: код и сброс (src/progress, server/progress)

Блок для страницы `/test` (страницу делает отдельный агент — вставить так):

```html
<div id="progress"></div>
<script type="module">
  import { mountProgressReset } from '/src/progress/resetBlock.ts';
  mountProgressReset(document.getElementById('progress'));
</script>
```

Блок показывает **код устройства** (6 символов) и кнопку **«Сбросить прогресс этого устройства»**
(стирает память кота на телефоне сразу и на сервере; сервер недоступен — сотрёт при следующем запуске).
Тот же блок есть в `?debug` → вкладка «Прогресс» (+ состояние синхронизации и последние сессии).

| Флоу | Как | Ожидание |
|---|---|---|
| Сброс по ссылке | `/?reset=1` | знакомство с нуля; `reset=1` пропадает из адреса; на сервере `data: {}` и `resetAt` |
| Сброс кнопкой | `/test` → «Сбросить прогресс этого устройства» | «Готово…»; следующий запуск — знакомство с нуля |
| Админ-сброс | `/test/admin/` → токен (`sudo cat /etc/ar-progress.env`) + код → «Найти» / «Сбросить» | на телефоне прогресс стирается при следующем запуске |
| Восстановление | познакомиться, затем в настройках Safari удалить только localStorage сайта (cookie оставить) → открыть | кот помнит имя и характер |
| Офлайн | авиарежим → открыть | запуск без задержки > 1,5 с, память из localStorage |
| Без имени | `/?noname` | на сервере в `sber-ar-cat:v1` нет `name`, кот имя помнит |

`?fresh` (как раньше) стирает только память знакомства; с сервером синхронизируется как обычное изменение.

| Очистить память кота | кнопка на /test | localStorage кота стёрт → следующий запуск — знакомство |

## Дом кота без камеры — `?flow=home` (src/home)

Пункт на странице `/test` уже добавлен (🏡 «Дом кота»). Флоу целиком в `src/home/homeMode.ts`: `prepareHomeFlow()` ставит
память «знакомы» до режиссёра, `HomeMode.runFlow()` уводит кота домой, как только идёт игра. В `src/debug/flows.ts`
`home` добавлять **не нужно** (`d.flow('home')` режиссёр не знает).

| Флоу | Как | Ожидание |
|---|---|---|
| Дом | `/?flow=home` | после посадки — вспышка-портал из кота, камера гаснет (индикатор камеры iOS пропадает), комната-гостиная; сверху «Гостиная» и точки зон |
| Сразу в зону | `/?flow=home&zone=kitchen` (`living`, `bedroom`) | та же комната, кот на кухне / в спальне |
| Свайп | влево / вправо по комнате или стрелки у краёв | кот перебегает в соседнюю зону вместе с камерой, подпись зоны меняется; у края — упор |
| Кухня | чип «Угостить» / «Какао» | миска с рыбкой у лап (7 с) и реакция «угостить»; кот пьёт какао (кружка в лапе) |
| Гостиная | «Потанцуем» / «Мячик» | танец; мячик на коврике прыгает, кот прыгает |
| Спальня | «Уложить спать» | кот ложится (клип сна), свет и окно темнеют; спит, пока не разбудят («Разбуди меня» / касание) |
| Обратно | «На карту» (вверху слева) или каталог → «На карту» | камера включается сразу, **без второго запроса разрешения**; кот ждёт у стекла, «где карта?» → карта найдена — кот на карте |
| Зов по потере | на карте убрать карту из кадра > 6 с | «Пойдём, покажу мой дом?» (если озвучено) и чипы «Пойдём!» / «Найду карту» |
| Каталог | лапка → «Игры» → «Мой дом» | то же, что «Пойдём!» |
| Память | уйти домой, закрыть вкладку, открыть | зона та же; в первую паузу кот зовёт домой (чипы) |

Новые реплики (`home_*`) пока без озвучки — в strict-режиме они не звучат, остаются подпись зоны и чипы.
Пакет на озвучку: `voice-src/el_batch_delta_2026-11-18-home.jsonl` (57 реплик, входит в `el_batch_all.jsonl`).
Снимки: `docs/ui/home_*.png` (`node scripts/home-shots.mjs` при запущенном `npx vite --port 4180`).

## Десктоп-просмотр кота — `?desktop` (src/input/orbit.ts)

Для продакта на Mac/ПК без камеры и карты: кот на фирменном фоне, его можно вращать и рассматривать.
`?desktop` — псевдоним `?nocard=off` (тот же гейтинг: lab — сразу, MVP — только с `from=test`); `?desktop&nocard=cam` — с камерой фоном.
На странице `/test` — карточка «💻 Кот на Маке (без камеры)».

| Действие | Как | Ожидание |
|---|---|---|
| Старт | открыть `/lab/?desktop` в Safari/Chrome на Mac → «Познакомиться» → «Позвать кота» | кнопка без значка камеры; браузер **не спрашивает** камеру, датчики и микрофон; кот выходит на фирменном фоне |
| Подсказка | первый запуск на устройстве без касания | плашка сверху «Тяни — повернуть · колесо — приблизить · двойной клик — сброс», пропадает через 9 с или при первом повороте; больше не показывается (`ar.orbitHint`). На телефоне/iPad — нет |
| Поворот | тянуть мышью по пустому месту или по коту (≥ 6 px) | площадка с котом поворачивается (влево-вправо), наклон вверх-вниз в пределах (сверху ↔ почти сбоку); тап/глажка **не** срабатывают; кот не разворачивается обратно к зрителю |
| Клик | клик по коту (сдвиг < 6 px) | как тап пальцем: реакция зоны (голова/щека/живот/лапа/хвост) |
| Глажка мышью | Shift + тянуть по коту | глажка, как пальцем (мурчание) |
| Правая кнопка | тянуть правой кнопкой | сразу поворот (без порога) |
| Зум | колесо мыши, щипок трекпада (Chrome — ctrl+wheel, Safari — gesture) | кот ближе/дальше, в пределах; страница не масштабируется |
| Сброс | двойной клик (если вид меняли) или R | исходный вид; двойной клик при исходном виде — как раньше, фирменный трюк |
| Клавиши | ← → поворот, ↑ ↓ наклон, + / − зум, R сброс | не работают, когда фокус в поле ввода (имя) и с Cmd/Ctrl (Cmd+R — перезагрузка) |
| Микрофон | кнопка микрофона (режим «по кнопке») | доступ к микрофону спрашивается только при нажатии; `?mic=auto` — как раньше |
| Телефон (`?nocard`, `?nocard=off`) | двумя пальцами тянуть / щипок | поворот и зум; один палец — тапы и глажка как раньше |

На десктопе не работает: встряска (нет датчиков — кнопка «Сдёрнуть наклейки» в каталоге/`?debug`), ориентация телефона,
камера; распознавание речи — офлайн Vosk работает в Chrome и Safari, если дать микрофон (Web Speech — по браузеру).
Снимок: `docs/ui/desktop_orbit.png` (`node scripts/desktop-orbit-shot.mjs` при запущенном `npx vite --port 4180`).

### Панель умений и «Тест» на десктопе (src/ui/deskPanel.ts, feature `desktop.panel`)

Только десктоп-просмотр (`?desktop`, устройство без касаний) и окно **≥ 900 px**; телефонный интерфейс не меняется. Панель справа 360 px,
кот остаётся по центру оставшейся области (`#app` сужается, камера пересчитывается). Пункты — из того же каталога, что лист на телефоне
(`UI.catalogGroups` → `actionCatalog.buildCatalog` + «Ещё» + дом), поэтому ничего не расходится (тест `tests/catalogGroups.test.ts`).

| Действие | Как | Ожидание |
|---|---|---|
| Открыть / свернуть | `Tab` или `\` (вне поля ввода), кнопка «›» в шапке, лапка «Что умею» в доке, язычок «Умения» у правого края | панель уезжает вправо, кот центрируется во всю ширину; состояние запоминается (`ar.deskPanel`) |
| Разделы «Умения» | прокрутить | **Ласка** (погладить, почесать, щекотка, щёчки, дай лапу, угостить, обнять) · **Трюки** (сальто, танец, фокус, прыжок, сидеть, помаши + эмоции: рассмеши, удиви, засмущай, подразни, закружи, усыпи) · **Игры** (песенка, загадка, повторяй; в lab — камень-ножницы, угадай рожицу, делай как я, если начало озвучено) · **Фразы** (привет, ты классный, пошути…) · **Образ** (пузыри/рисунок/к стеклу по характеру, тук-тук, наклейки N/M, другой кот, **«Сдёрнуть наклейки»** — вместо встряски) · **Мир** (мой дом / на карту, комнаты, когда кот дома; пересадить на карту) · **Служебное** (микрофон) · «Вид и звук» (сбросить вид, звук). Все пункты сеткой без горизонтальной прокрутки, красные точки «новое», счётчик «попробовано N/M» |
| Поиск | `/` — фокус; набрать «класс», «щек», «сальт» | остаются совпадения; первое обведено зелёным; `Enter` — выполнить его; `Esc` — очистить / выйти из поля |
| Чипы кота | цифры `1`–`9` | выполняется чип с этим номером (как кнопка над доком); подсказка с клавишей — во всплывающем title |
| Вид | `← → ↑ ↓ + − R` | как в разделе выше (вращение площадки) |
| «Тест» | вкладка в шапке: в lab всегда, в MVP — с `?debug` или `?from=test` | состояние (характер, фаза, диалог, дрёма, микрофон, дом); **Характер**; **Состояния**: дрёма, «мне грустно», карта потеряна / найдена, перелокализация (потеря → через 1,5 с найдена), «давай другого», outro, флоу игр; **Дом**: домой/на карту, кухня/гостиная/спальня; **Микрофон**: режим; **Эмоция лица** (все пресеты face.json); **Событие · реплика**: поиск по id событий content/events.json (метка «озвучено/без записи») и по репликам всех характеров — клик играет событие/реплику с пузырём и голосом; **Сказать за ребёнка**; **Лог** последних 20 строк (🗨 — реплика прозвучала, красным — пропущена/не выбрана, синим — команды теста) |
| Узкое окно | сузить окно < 900 px | панели нет, приложение во всю ширину, лапка открывает лист как на телефоне |

Снимки 1440×900 (lab `?desktop`): `docs/ui/desktop_panel.png`, `docs/ui/desktop_panel_test.png`.
