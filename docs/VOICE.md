# Голос: озвучка, липсинк, распознавание, повтор, громкость

Прообраз — «Говорящий Том»: кот слушает ребёнка, отвечает голосом, **повторяет** сказанное смешным голосом,
рот двигается в такт. Всё работает на телефоне, звук ребёнка никуда не отправляется.

## Озвучка (Piper)

**Голоса**: `ru_RU-ruslan-medium` (Хулиган, Добряк) и `ru_RU-irina-medium` (Блёстка) — из пресетов
`content/src/<характер>.meta.json → voice` (`piperVoice`, `pitchSemitones`, `rate`). `denis` и `dmitri` C++-релиз
Piper 2023.11.14-2 не грузит («Phonemes must be one codepoint»).

**Обработка** (`src/audio/dsp.ts`, всё на JS, ffmpeg не нужен):
1. Piper, `--length_scale = 1/rate` (темп — «естественный», самой моделью), `noise_scale 0.6`, пауза между фразами 0.15 с;
2. обрезка тишины по краям (−45 дБ от пика, запас 50 мс);
3. **сдвиг тона** на `pitchSemitones` с сохранением длительности: фазовый вокодер с фазовой привязкой к пикам
   (Laroche–Dolson), окно ~46 мс, + пересэмплирование окном Ланцоша. Rubberband/ffmpeg на сервере нет (нет root);
4. громкость **−16 LUFS** (BS.1770: K-фильтр, гейты −70/−10), пик ≤ −1.5 dBFS (лимитер с упреждением 5 мс);
5. **MP3 32 кбит/с моно 22.05 кГц** (`wasm-media-encoders`, LAME в wasm). MP3 — потому что его декодируют все
   браузеры, включая старые iOS (Opus в Safari — только с 17-й версии), и кодировщик работает без ffmpeg.

**Имена файлов** — `<характер>/<id>.<хэш>.mp3`, хэш = текст + голос + тон + темп + битрейт + версия обработки.
Поменяли текст — новый файл; старый удалится при следующем полном прогоне. Кэш браузера по таким именам безопасен.

**Слоты** `{name}`, `{answer}`: реплика режется на «префикс» и «суффикс», каждый озвучивается отдельно; имена из
`content/names.ru.txt` (227) и ответы загадок — отдельными файлами для каждого характера. В рантайме три куска
склеиваются в один буфер (пауза 40 мс), cues — со смещениями. Имени нет в словаре → вся фраза синтезом браузера
(и кот вообще не произносит имена не из словаря — это правило сценария).

**Загадки** (`content/dialogs.json → riddles`): вопрос и подсказка озвучиваются с id `<характер>.riddle.<id>.q|hint` —
так их ищет director.

### Манифест

```
voice/manifest.json                       ← индекс (маленький, грузится при старте)
  { version, codec, lipsync, personas: { hooligan: { manifest: "hooligan.<хэш>.json", lines, names, answers } } }
voice/hooligan.<хэш>.json                 ← манифест характера (~95 КБ, ~25 КБ gzip), грузится лениво
  lines: { "<id>": { f, d, o, c, t } }    f — файл, d — длительность, o — начало звука, c — cues «X0 D120 …», t — текст
  parts: { "<id>": { t, slot, a, b } }    реплики со слотом
  slots: { name: { "Саша": {…} }, answer: { "огурец": {…} } }
voice/hooligan/*.mp3
```

**Ленивая загрузка**: при старте — только индекс; манифест характера — при первой его реплике (или
`voice.usePersona(id)`); MP3 — по одной реплике при проигрыше (декодированные буферы — LRU на 48 шт.).
Предзагрузка: `voice.preloadEvents(persona, ['intro','ask_name',…])` (app.ts грузит первые события сценария сразу),
`voice.preload(persona, template, lineId)`.

пишется всегда. Новые файлы попадут на сайт со следующей сборкой (любой push в `main`).

## Озвучка ElevenLabs (основная)

Приоритет в плеере: **ElevenLabs → Piper → синтез браузера**. Голоса — `content/src/<характер>.meta.json → voice.elevenVoiceId`,
модель `voice.elevenModel` (`eleven_v4`). Озвучиваются **все** реплики, вопросы и подсказки загадок, а реплики со слотом
(`{name}`, `{answer}`) — кусками «до» (`<id>~a`) и «после» (`<id>~b`) плюс каждое имя из `content/names.ru.txt` и каждый
ответ загадки отдельным файлом для каждого характера (`<характер>.slot.name.<Имя>`, `<характер>.slot.answer.<ответ>`);
в рантайме куски склеиваются, как у Piper. Имени нет в словаре — фраза уходит в Piper/синтез.

**Интонация** — английские пометки в квадратных скобках перед текстом (`scripts/voice/el-common.mjs → TAGS`):
`happy` → `[cheerfully]`, `cheeky` → `[mischievously]`, `caring` → `[softly]`, `whisper` → `[whispers]`, `sleepy` → `[sleepily]` и т. д.;
`neutral` — без пометки. Русских слов в скобках быть не может: модель прочитала бы их вслух (build.py вырезает `[...]` из реплик).
Ударений `+` и `´` пайплайн не понимает (ни Piper/espeak, ни ElevenLabs) — неоднозначные слова переписаны
(«Здоро́во!» → «Салют!», «замок» в загадке → другая загадка, «хлопок» → «кто хлопнул»), везде «ё».
**Текст для синтеза** (`scripts/voice/spoken.mjs`): «СберKids» → «Сбер Кидс» — в пузыре остаётся бренд, в речь — по-русски.

**Пакет** `voice-src/el_batch_all.jsonl` — всё, чего ещё нет на сервере или что изменилось; собирает
`node scripts/voice/el-batch.mjs` (его же зовёт `python3 content/build.py`). «Уже озвучено» —
`voice-src/el_voiced_base.tsv`. С 17.11 база пуста: 150 реплик первого прогона на сайт не попали (кот на них молчал),
поэтому в пакете всё; раннер сам пропускает то, что уже лежит на сервере с тем же хэшем. Что добавлено к озвучке за раз —
`voice-src/el_batch_delta_<дата>.jsonl` (для справки и подсчёта символов). Строка пакета:
`{ id, kind: line|part|slot, persona, voice_id, model_id, text (в API), plain (для фонем), t (субтитр), out, h, chars, … }`.

## Липсинк

### Русский путь (по умолчанию)

1. **Фонемы**: `espeak-ng -v ru --ipa` (тот же фонемизатор, что внутри Piper; на сервере — из комплекта Piper).
   Нет espeak — буквенные правила (`phonesFromText`).
2. **Тайминг**: Piper (C++-релиз) не отдаёт длительности фонем, поэтому — принудительное выравнивание Витерби
   по кадрам 10 мс: громкость (лог-RMS, нормирована 5–95 перцентилем) и доля пересечений нуля. Модель «класс фонемы →
   ожидаемые признаки»: гласные — громкие и тональные, сонорные — средние, фрикативные — шумные, смычные — тихие,
   паузы — тишина; у каждой фонемы минимальная длительность (гласная 40 мс, согласная 30 мс), паузы между словами и
   клаузами можно пропустить.
3. **Сглаживание**: короткие (< 40 мс) формы поглощаются соседями, кроме смыкания губ A (≥ 30 мс); согласный перед
   «у/о» получает округлую форму заранее (предвосхищение); в рантайме переход между формами ~70 мс.

### Маппинг русских фонем → формы рта Rhubarb

| Форма | Звуки | Почему |
|---|---|---|
| **A** (губы сомкнуты) | м, б, п (+мягкие) | губно-губные |
| **B** (зубы сомкнуты, рот чуть открыт) | и, ы; т д н с з ц к г х й р; **ш ж щ ч** | у Rhubarb SH/CH/ZH/JH — тоже B; H («язык») для шипящих неверна |
| **C** (открыт) | э, е, редуцированный [ə] | |
| **D** (широко) | а, я, [ɐ] | |
| **E** (округлый) | о, ё, [ɵ] | |
| **F** (трубочка) | у, ю | |
| **G** (зубы на губе) | ф, в | губно-зубные |
| **H** (язык) | л — если длиннее 50 мс, иначе B | Rhubarb даёт H только «долгому L» |
| **X** | паузы | покой |

### Сравнение стратегий (`--compare`, реплики Хулигана, Piper ruslan, сервер swe)

| | фонемы + выравнивание | амплитуда |
|---|---|---|
| корреляция «раскрытия рта» с огибающей | 0.55 (было 0.48 до учёта безударных) | 0.79 |
| гласные легли на громкие кадры | 79% (на eSpeak-голосе — 99%) | — |
| разных форм в реплике | 6–9 | 3–4 (X, B, C, D) |
| смыкания на М/Б/П | все (на провале громкости) | нет (только случайные A на провалах) |

Корреляция с огибающей у «амплитуды» выше **по построению** (она и есть огибающая), поэтому это проверка тайминга,
а не качества. Фонемный путь даёт правильные формы (о/у — округлые, м/б/п — сомкнутые, а — широкий) при совпадающих
паузах и открытиях — **выбран по умолчанию**. Амплитуда оставлена: `?lips=amp` или в debug-вкладке, а также для
повтора (у фразы ребёнка нет текста) и для записей без cues.

## Распознавание (ASR)

| Движок | Включение | Приватность |
|---|---|---|
| **Vosk** (vosk-browser, Kaldi/wasm) | **по умолчанию** | полностью офлайн, звук не покидает телефон |
| Web Speech API | `?asr=web` | Chrome отправляет звук в Google, Safari — Apple. На пилоте с детьми — **нельзя** |

- Модель `vosk-model-small-ru-0.22` (~45 МБ, Apache-2.0) → `/models/vosk-ru-small-0.22/model.tar.gz`
  (на сервере: `/srv/ar-extra/models/…`, исходный zip — `/var/lib/vershov-commander/ar/vosk/`; см. DEPLOY.md). Движок vosk-browser — отдельный чанк ~5.8 МБ (2.4 МБ gzip).
- Загрузка **лениво**: через 3 с после «Разбудить» (не при «экономии трафика») или при первом нажатии микрофона;
  прогресс — в подсказке под кнопкой («Загружаю распознавание… 42%»). Файл кладётся в **Cache Storage**
  (`ar-cat-vosk-v1`) — повторный визит без сети. Сам воркер Vosk качает модель по тому же адресу (из HTTP-кэша:
  `/models/*` отдаётся с `immutable`).
- **Грамматика**: распознаватель ограничен фразами `content/intents.ru.json` + имена `names.ru.txt` + **ответы
  загадок всех характеров** (`riddleWords()`: answer, ключевые слова, частые формы основ «мишк*» → «мишка»…) +
  частые детские фразы без команды (`CHAT_PHRASES`: «как дела», «мяу», «ты меня слышишь»…) + связки + `[unk]`
  (`grammarPhrases()`). Слова с «ё» — в обоих написаниях (слов, которых нет в словаре модели, Vosk не учитывает).
  Всё остальное Vosk выдаёт как `[unk]` — это тоже «ребёнок что-то сказал» (`asr.lastUnk`). `?grammar=0` — свободный
  словарь (отладка).

### Интенты (`src/voice/intents.ts`)

- нормализация: нижний регистр, ё→е, без знаков;
- слово совпадает: точно (1.0) → по основе, стемминг-lite (0.92) → по префиксу, если в словаре основа («жвачк», 0.88)
  → **Левенштейн ≤ 1 для слов длиннее 4 букв** (0.78; «сальта», «потонцуй») → «ь» и «тс/ц» («таньцуй»);
- фраза из нескольких слов — по порядку, допускается одно лишнее слово; длинные фразы специфичнее («не хочу» > «хочу»);
- **отрицание** перед фразой («не танцуй», «не повторяй за мной») снимает её;
- **безопасность первой**: sad/scared выигрывают при любом уверенном совпадении;
- `context: only_after_question` — только в окне ответа на вопрос кота;
- уверенность < 0.6 → `unknown`; имя: «меня зовут …», «я …», в окне имени — одиночное слово; `known` — есть в словаре.
- Тесты: `tests/voice-intents.test.ts` — по 3 фразы на каждый интент + детские ошибки.

## Слушает и отвечает (не болтает сам) — `utterance.ts`, `turn.ts`, `scenario/initiative.ts`

Жалоба с iPhone 17.11: «не реагирует на голос, общается сам». Причины и что сделано:

| Причина | Исправление |
|---|---|
| В «слушаю всегда» микрофон не открывался **никогда**: при создании движка (до жеста, AudioContext ещё нет) `MicInput.open()` синхронно возвращал `false`, и `finally { opening = null }` срабатывал *раньше* присваивания `opening ??= …` — в `opening` навсегда оставался готовый `false` | `open()` сначала присваивает промис, потом очищает; `mic.ensureOpen()` при возврате во вкладку; `track.onended` (звонок/Siri) — микрофон считается закрытым и открывается снова |
| Ответы загадок («огурец», «лампочка»…) не были в грамматике → `[unk]` → ответ никогда не засчитывался | `riddleWords()` в грамматике |
| Свободная фраза вне словаря → только `[unk]` → пустой текст → тишина | `[unk]` считается речью: кот отвечает «не понял» |
| Фильтр «непонятое в „слушаю всегда“ — молча» ни разу не работал как задумано (Vosk сообщает `idle` раньше результата — причина слушания уже сброшена) | правила в `classifyUtterance()`; причина фразы хранится в `engine.utter` |
| Кот говорил сам каждые ~13 с (filler) + «ты тут?» через 10 с, в том числе когда ребёнок говорил | `InitiativeGate` (ниже) |
| `clap` от тапов по телефону — «Кто хлопнул?» каждые 3 с | хлопок в течение 1 с после касания не считается; пауза реплик `clap` 20 с, `loud` 15 с |
| Vosk: частичный результат дублировал итоговый («привет привет») | частичный сбрасывается при итоговом |

**Каждая фраза — ответ** (`classifyUtterance`): понятая команда → действие (даже короткое «да», «стоп»);
непонятая речь (голос по VAD ≥ 0,5 с и есть слова или `[unk]`) → 1-й раз `unknown` («Чё? Не расслышал»), 2-й —
`help` («Я умею сальто, танцы и загадки. Скажи «сальто»») + кнопки-подсказки, дальше по очереди; если реплика
остывает — подменяет вторая (ответ есть всегда). Шум — короче 0,5 с, только «а/ну/я», пусто — без ответа.
«Держи и говори» и окно ответа на вопрос — порог ниже (ребёнок явно обращается). В «слушаю всегда» непонятое
подряд — не чаще раза в 4 с (взрослые разговаривают рядом). Интент `help` — «что ты умеешь», «давай поиграем».
«Да/нет» на реплику-вопрос вне диалога — короткий ответ `yes`/`no` (раньше — молчание).

**Подсказка над микрофоном**: «Слушаю…» и «ушки» (`listen_ears`), пока идёт фраза/окно ответа; после фразы —
распознанный текст «…»; слова вне словаря — «Слышу тебя, но слова не разобрал»; пусто после кнопки/вопроса —
«Не расслышал — скажи ещё раз».

**Очередь слова** (`turn.ts`): VAD услышал голос → кот не начинает новую реплику (`VoicePlayer.hold` 5 с, отпускаем,
когда фраза разобрана); во время реплики кота — перебивание голосом (как раньше). Окно ответа после реплики-вопроса — **8 с**.

**Инициатива кота** (`InitiativeGate`, filler и «ты тут?» `silence`): не чаще раза в **15–20 с**; не пока VAD слышит
голос; ≥ 10 с после фразы/касания ребёнка; ≥ 10 с после любой реплики кота, ≥ 15 с после реплики-вопроса;
не во время диалога, поддержки, речи кота. `silence` от Input, пришедшее «не вовремя», откладывается.
Тесты: `tests/voice-turn.test.ts`.

## Режимы микрофона

- **push-to-talk** (`?mic=ptt`): держи кнопку и говори. Нажал, пока кот говорит, — **перебил**.
- **окно ответа**: director сам открывает микрофон после вопроса кота (`DirectorDeps.listen(ms, mode)` →
  `engine.listenFor`; объектом: `engine.listen({ windowMs: 5000, expect: ['yes','no'] })`). Микрофон включается,
  когда кот договорил (+250 мс), закрывается по концу фразы ребёнка (VAD) или по таймауту.
- **«слушаю всегда»** (по умолчанию с 17.11; выбор запоминается): микрофон открыт всё время — окно ответа (8 с) после любой реплики кота,
  кончающейся на «?», и перебивание голосом (речь на 22 дБ выше шума ≥ 200 мс — с запасом на эхоподавление).
- **Кот не слушает себя**: на время реплики и 250 мс после — распознавание, VAD и повтор не получают звук.
- **Перебивание**: реплика затухает за 120 мс (`VoicePlayer.fadeOut`), следующие реплики ждут
  (`VoicePlayer.hold`), пока ребёнок говорит; очередь со своими приоритетами не трогается.

## Повтор («эхо»)

Диалог `echo` в `content/dialogs.json`: «повторяй за мной» → кот отвечает → окно `listen` в режиме `echo` (20 с).

1. VAD: начало — энергия выше шума на 12 дБ ≥ 120 мс (+250 мс записи «до»), конец — **400 мс тишины**, максимум **6 с**.
2. Запись — только в памяти. Если модель Vosk загружена — фраза проверяется маленькой грамматикой стоп-слов
   («хватит», «стоп», «не повторяй», «перестань») → выход из режима.
3. Обработка в воркере: 24 кГц → **сдвиг тона +`echoPitchSemitones`, темп `echoRate`** (пресет характера) фазовым
   вокодером — тон выше без ускорения («бурундук» — только по тембру, без артефактов скорости) → −16 LUFS.
4. Сценарию приходит «ребёнок сказал» (`'…'`), director ставит повтор в очередь → `VoicePlayer.echo()` играет
   запись; рот — по амплитуде, клип `echo_speak`. Через сценарий же — `echo_done` (после 1-го и каждого 4-го).
5. **Исходная и обработанная записи затираются нулями сразу после проигрыша**; не сохраняются и не отправляются.
6. Выход: стоп-слово / таймаут окна 20 с / кнопка. Без сценария: `__voice.echo.start()` — кот сам повторяет всё,
   автовыход через 20 с без речи. События движка: `echo_start`, `echo_done {count}`, `echo_stop {reason}`.

## Громкость без распознавания

| Событие | Условие | Пауза |
|---|---|---|
| `loud` (крик) | уровень > −14 dBFS и на 30 дБ выше шума ≥ 400 мс | 15 с |
| `clap` (хлопок) | пик > −12 dBFS, на 28 дБ выше шума, громкая часть < 80 мс, перед ней ≥ 150 мс тишины; не в течение 1 с после касания экрана | 20 с |
| `whisper` (шёпот) | фраза ≥ 500 мс, средний уровень < −38 dBFS и «шумная» (доля пересечений нуля > 0.12 — нет голосовых связок) | 8 с |

Шумовой порог: **калибровка первые 2 с после включения микрофона** (30-й перцентиль), дальше медленно следует за
тишиной. События уходят в `director.interaction('loud' | 'whisper' | 'clap')` (когда кот уже на карте).
Пороги — `window.__voice.thresholds` (меняются на лету).

## iOS и звук

- **Один `AudioContext` на всё** (`src/audio/audio.ts` создаёт его сам, `latencyHint: 'playback'`, и отдаёт Howler):
  проигрыш, микрофон, голос, фанфары, повтор. Howler без этого на iOS (48 кГц) закрывал первый контекст и создавал
  второй (стенд: 2 контекста → 1), а на первом жесте создавал пул из 10 HTML-Audio — выключено (`html5PoolSize = 0`).
- **Аудиосессия (Safari 17+) — один раз** в жесте «Разбудить кота»: `play-and-record`, если микрофон поддерживается
  (то же, что iOS включает сама при захвате; переключатель «Без звука» не глушит), иначе `playback`. Микрофон её больше
  не переключает: смена `playback ↔ play-and-record` при открытии/закрытии микрофона на iOS прерывала камеру.
  `?session=playback|play-and-record|auto|off` — для проверки на устройстве.
- **Микрофон** — один `getUserMedia` за страницу и **после** камеры (`App.wake`: сначала видео, потом `resumeAuto`);
  до жеста не открывается вовсе (`Audio.unlocked`). Не закрывается: повторный `getUserMedia` на iOS рвёт видео.
- **AudioWorklet** вместо ScriptProcessor (`micWorklet.ts` + `micDsp.ts`): кадры 10 мс для VAD и 16 кГц ×32768 для
  Vosk считаются в потоке звука; главному потоку — одно сообщение на ~85 мс, Vosk получает готовые 16 кГц без
  пересчёта (втрое меньше данных в его воркер, Kaldi не пересэмплирует). Нет AudioWorklet — ScriptProcessor с той же
  обработкой; `?micnode=sp` — принудительно. Стенд `scripts/bench/audio.mjs`: главный поток с открытым микрофоном
  (headless, CPU ×4) — было ≈ +35 п.п. к «микрофон закрыт», стало ≈ +4.
- **Синтез и Piper в проде не используются**: есть `voice/el/manifest.json` — Piper-индекс не качается, `speechSynthesis`
  не трогается (ни в жесте, ни `getVoices`, ни `cancel`); реплики без записи молчат. `?piper`, `?synth` — для отладки.
- Кэш декодированных реплик — LRU по объёму 12 МБ (≈ минута звука 48 кГц), предзагрузка — по 2 декодирования сразу.
- Старые iOS без `audioSession`: при включённом «Без звука» Web Audio молчит — подсказка через 2.5 с после старта.
- Ducking: говорит кот — sfx/фон −8 дБ; слушаем ребёнка — −14 дБ (меньше своего звука в микрофоне).
- Кнопка «Без звука» в интерфейсе глушит и реплики (обрывает текущую).

## Ограничения

- Голос Piper — заглушка «приличного качества»; для запуска нужен актёр (детский/молодёжный тембр). Записи актёра —
  через `voice-src/` + `npm run voice:build` или заменой MP3 с тем же манифестом.
- Тайминг фонем приблизительный (нет выравнивания от самой модели); для актёра стоит прогнать MFA (Montreal Forced
  Aligner) с русской моделью — формат cues тот же.
- Vosk (vosk-browser 0.0.8): движок 5,8 МБ JS (2,4 МБ gzip, wasm внутри), модель — архив ~45 МБ. Воркер сам качает и
  распаковывает архив в IndexedDB, а при каждом старте читает распакованную модель из IndexedDB в свою память (MEMFS)
  и ещё раз — в кучу wasm: **две копии модели в памяти воркера навсегда** (так устроена библиотека; лечится только
  форком — удалять файлы MEMFS после `new Model`). Свою копию архива в Cache Storage и 90 МБ буферов в главном
  потоке при первой загрузке больше не держим (метка `ar.vosk.ready` в localStorage).
- Vosk small: на слабых Android первая инициализация 3–6 с; детская речь распознаётся хуже взрослой — поэтому
  грамматика и чипы-подсказки как запасной ввод.
- Повтор: вокодер на телефоне — ~0.3–1 с на фразу (в воркере, кадр AR не тормозит).
- Перебивание голосом работает только в «слушаю сам» и зависит от эхоподавления телефона.
