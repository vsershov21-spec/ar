## Поверхности (описание, в работу не брали)
Кот живёт не только в карте на столе — те же точки контакта (кот, его реплики, мини-онборды сервисов) можно вывести
на другие поверхности Сбера. Персональных данных ребёнка поверхность не получает: только метка точки и шаги (как onb_step).
- 🔜 **Касса / платёжный терминал** (магазин, школьная столовая): после оплаты детской картой на экране терминала —
  кот на секунду выглядывает из «карты» и машет («Мур! Оплачено»), QR «Позови кота домой» → /mvp?src=<точка>. Нужен
  формат экрана терминала (SberPay / смарт-терминал Эвотор), согласование с эквайрингом, без звука по умолчанию.
- 🔜 **Умная колонка (SberBoom / Салют)**: голос кота тем же голосом ElevenLabs — загадки, «спокойной ночи»
  (кровать «Мира кота»), повторы онбордов голосом («А это СберKids…»); сценарии без экрана, ответы «да/нет»;
  смарт-апп Салюта, привязка к детскому профилю родителя, без записи речи ребёнка.
- 🔜 **2ГИС**: метка «здесь живёт кот» в точках раздачи QR и у партнёров (Самокат-даркстор рядом, отделения):
  карточка организации с кнопкой «Разбудить кота» → /mvp?src=<точка>; AR-«след лапок» до отделения как маршрут.
  Нужны данные 2ГИС (рекламный кабинет / API карточек) и разрез воронки по src.
- ✅ Персонажи 26.11 (часть A): выбор кота листом после имени «Выбери своего кота» и смена «Позвать другого кота» (вспышка, без наклеек), фирменный предмет при появлении (скейт / какао / зеркальце), баг «сменилась подпись, модель прежняя» (гонка загрузок моделей), хват предметов по поверхности (пальцы до касания) — PROJECT_MAP §2.1а, docs/qa/props/GRIP.md
