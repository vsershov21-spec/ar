# Логика жизни кота: простая модель

Цель: ребёнок 6–13 лет за минуту понимает, как кот себя ведёт. Кот отвечает на действия сразу, сам говорит редко и по делу,
каждая игра заканчивается словами, а не обрывом. Код: `src/scenario/machine.ts` (автомат), `src/scenario/initiative.ts`
(лестница тишины), `src/persona/lineQueue.ts` (очередь реплик), `src/director.ts` (исполнение). Тесты-сценарии:
`tests/directorScenario.test.ts` (режиссёр на фейковом времени, настоящий контент и набор озвученного).
Расшифровки headless-сессий: `docs/scenario/transcripts/` (стенд: `scripts/scenario/audit.mjs`).

## Модель в 8 строк

1. **Знакомство** (новый ребёнок, один раз): карта → поздравление и привет → «как тебя зовут?» → ответ → «я — …» → «как со мной играть» (обучалка). Шаги не перебиваются: касания в это время — только клип и эмоция, без слов.
2. **Возвращение** (уже знакомы): одна тёплая реплика («Маша, привет! Я по тебе скучал» или «давно не виделись») и трюк без слов — сразу игра.
3. **Свободная игра**: действие ребёнка (касание, кнопка, фраза) всегда главнее. Реакция начинается сразу и обрывает собственную болтовню кота (мысль вслух, «ты тут?», предложение, «с возвращением», зов в СберKids).
4. **Мини-игры** (загадка, повторялка, угадай эмоцию, камень-ножницы-бумага, повтори движение, «Хочешь загадку?»): касания не перебивают их словами; кнопка — явная команда: игра заканчивается, команда выполняется (кнопка «Танцуй» посреди загадки — танец, а не «неверный ответ»). Ответ раньше конца вопроса снимает недоговорённый вопрос.
5. **Конец мини-игры — всегда словами**: «ещё загадку?» → тишина → «Окей, мозги отдыхают»; «пока?» → тишина → «остаёмся»; повторялка → «хватит» или 20 с тишины → «режим попугая выключен»; игры с выбором → «ещё раунд?» → нет/тишина → «ладно, поиграем потом» (`game_bye`).
6. **После действия ребёнка кот сам молчит минимум 12 с.** Дальше — лестница тишины (отсчёт от последнего действия): 12 с «ты тут?» → 30 с предлагает занятие → 55 с мысль вслух → 80 с другое занятие → 110 с дремлет.
7. **Предложения — по кругу без повторов**: загадка → камень-ножницы-бумага → повторялка → угадай эмоцию → танец → повтори движение → загадка… (неозвученные пропускаются). «Мне скучно» — тоже следующее предложение из круга. «Да» — занятие начинается, «нет» — «ладно», тишина — кот не настаивает. Между репликами кота сам по себе — не меньше 12 с, ни одна запись не звучит дважды за 3 мин тишины.
8. **Дрёма**: кот спит молча, пока ребёнок не разбудит. Касание будит («А? Я не спал!»), кнопка или фраза — будят и сразу выполняются. После — лестница с начала.

## Состояния

```
          новый ребёнок                       уже знакомы
 карта ──► ЗНАКОМСТВО ──────────┐   карта ──► ВОЗВРАЩЕНИЕ ──┐
                                ▼                           ▼
                        ┌──► СВОБОДНАЯ ИГРА ◄──────────────────────────┐
     действие ребёнка   │      │  тишина (лестница)                     │
     ───────────────────┘      ├─► «ты тут?» / мысль вслух ─────────────┤
                               ├─► предложение ─ да ─► МИНИ-ИГРА ───────┤ (конец — словами)
                               │                 нет/тишина ────────────┤
                               └─► ДРЁМА ── касание/кнопка/фраза ───────┘
   «Другой кот» → СМЕНА (наклейки, встряска, «новый я!») → СВОБОДНАЯ ИГРА
   карта пропала > 1,5 с → «где карта?» (лестница на паузе) → вернулась → «вот она» → СВОБОДНАЯ ИГРА
   4–6 мин → зов в СберKids (только в тишине: не поверх реплики, игры, дрёмы и без карты; иначе через 10 с)
```

## Кто кого прерывает (очередь реплик)

| Приоритет | Что | Правило |
|---|---|---|
| 3 | безопасность: «грустно», «страшно»; «где карта?» | обрывает всё, очередь сбрасывается до неё |
| 2 | сценарий и диалоги: знакомство, вопросы мини-игр, смена кота, «с возвращением», зов в СберKids | встаёт в очередь по порядку (до 6). Шаги знакомства неперебиваемые; «с возвращением», зов в СберKids, «новый я» — перебиваемые |
| 1 | реакция на действие ребёнка | сразу: обрывает фон и перебиваемый сценарий; старые реакции из очереди выкидываются. Во время знакомства и мини-игры касание — без слов |
| 0 | инициатива кота: «ты тут?», мысль вслух, дрёма | только в полной тишине (лестница) |

Реплика сценария (`say` из автомата/диалога) всегда не ниже 2, даже если событие само по себе — реакция (`no` в «Хочешь загадку? — Нет»).
Ответ ребёнка на вопрос узла снимает реплики этого узла, которые ещё не прозвучали (`LineQueue.drop` по тегу «диалог.узел»).

## Озвучка и пузырь

- Реплика без записи ElevenLabs не выбирается и не показывается (строгий режим: picker `strict`, `Director.react`, загадки).
  Если у события нет ни одной озвученной реплики, кот молчит, но клип и эмоция реакции остаются. Пока вопросы «Хочешь загадку?»
  не озвучены, на шаге «предложить» звучит озвученная подсказка («Скажи «повторяй за мной»…», событие `bored`).
- Пузырь показывается, когда начинается голос, и исчезает вместе с концом реплики (`UI.hideBubble`), а не по таймеру длины текста.

## Кнопки «Удиви» и «Подразни»

Раньше «Удиви» отправляла событие `clap` («Кто хлопнул?» без хлопка), «Подразни» — `poke_combo` («Три раза в одно место?» после
одного нажатия). Теперь у них свои события `surprise` и `tease`; `clap` — только настоящий хлопок в микрофон, `poke_combo` — три тапа подряд.

## Проверка продактом

- `?fresh` — знакомство с нуля (стирает имя, характер, «уже знакомы»).
- `?debug` — лог режиссёра: «тишина 30 с → offer», «снят недоговорённый вопрос riddle.hint», «🔇 нет записи …», «проснулся».
- Стенд: `npx vite build && node scripts/scenario/fake-voice.mjs dist 4 && npx vite preview --port 4173 --strictPort &`,
  затем `node scripts/scenario/audit.mjs` — шесть сессий (3 характера × новый/повторный), расшифровки в `docs/scenario/transcripts/`.
  В сводке расшифровки `echo:…` «без записи» — это повторялка: на телефоне кот играет запись голоса ребёнка, на стенде микрофона нет.
  `docs/scenario/transcripts/before/` — те же сессии до правок (коммит 480c509).

## Мини-игры с выбором (ночь 18.11, `docs/scenario/CONTENT_NIGHT.md`)

Диалоги `emo`, `rps`, `simon` в `content/dialogs.json`, варианты — блок `games`. Автомат хранит `state.game` (что загадал кот,
раунд), ответ ребёнка приходит событием `game_answer` (режиссёр разбирает слова по `keywords`, кнопки движений — по `intents`).

- **Угадай эмоцию**: «какой я?» → кот показывает эмоцию лицом и клипом (`game_show`, после реплики) → ответ голосом;
  мимо → показ ещё раз → мимо/тишина → «это был грустный я» → «ещё?». «Ты грустный» в этой игре — ответ, «мне грустно» — поддержка.
- **Камень, ножницы, бумага**: кот выбирает заранее, «раз, два, три!» → ребёнок говорит → «у меня камень» + кто выиграл → «ещё?».
- **Повтори движение**: кот показывает движение (клип реакции: прыжок, сальто, танец, помахать, сесть) → ребёнок жмёт такую же
  кнопку или говорит. **Кнопка движения в этой игре — ответ**, любая другая кнопка завершает игру, как везде. Три раунда → победа.
- Касания во время игры — без слов (клип и эмоция). Безопасность («мне грустно», «страшно») прерывает любую игру.
