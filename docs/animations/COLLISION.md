# Руки и ноги не проходят сквозь тело и одежду

Требование владельца (18.11, 19.11 — «руки проникают в наушники»): ни в одном движении кисть, предплечье, плечо не проходят сквозь голову, кепку, уши,
наушники, капюшон, шарф, торс, ноги и реквизит; ноги — друг сквозь друга; «руки в карманах» кончаются у входа в
карман, а не внутри торса. Делает это `src/character/bodyCollide.ts` (`BodyCollider`), каждый кадр после клипа
(`GlbCharacter.update` → `collider.apply(dt)`), для любого клипа — anims_v1, монтаж, Meshy.

## Прокси

Каждый прокси — эллипсоид или капсула в системе своей кости (едет вместе с ней).

| источник | что даёт | когда |
|---|---|---|
| `public/models/v2/<кот>_colliders.json` (экспорт модельщика) | все прокси и карманы | модели v2 (`?models=v2`, `character/modelVariant.ts collidersUrl`); файл есть — главнее всего (`GlbCharacter.loadColliders`, после загрузки кота) |
| `public/models/<кот>_v1_colliders.json` (19.11) | то же для v1 — тем же `scripts/models/colliders.py` по v1 GLB | модели v1 (по умолчанию); наушники Хулигана v1 запечены в сетку тела — по вершинам с меткой «наушники» (цвет альбедо, `mesh_parts.label_parts`): чашки — капсулы по своей оси, дуга — 12 секторов средней линии вокруг шеи |
| меш тела в позе покоя | `torso` (Hips/Spine*), `neck`, `head` — эллипсоиды, 85-й перцентиль вершин | без файла (чужая модель `?glb=…`) |
| меши одежды по имени | `cap` (`Cap_*`), `headphones`, `scarf`, `bow`, `skirt` — эллипсоиды, 90–95-й перцентиль | меш есть; работает, пока меш виден (чужая одежда спрятана сменой характера) |
| запас по характеру `PERSONA_PAD` | кепка / наушники (Хулиган), шарф (Добряк), бант / юбка (Блёстка) — масштаб головы/шеи/таза | меша одежды нет |
| кости ног | `thigh_L/R` (для рук — «сердцевина» 0,8), `shin_L/R` — капсулы по вершинам ног | всегда |
| кости ушей | `ear_L/R` — капсула от `*Ear1` до кончика, в системе головы | есть кости ушей |
| карманы худи | две сферы у переднего нижнего края торса | без файла — по торсу |

## Точки проверки

**Рука по поверхности (19.11, «руки проникают в наушники — такого быть не должно»).** Раньше кисть проверялась точками
на оси кости (запястье, кончик лапы, середина предплечья) с запасом 0,028 роста — сетка лапы толще, и после коррекции
лапа оставалась в наушниках/голове/кепке. Теперь при загрузке из сетки скина (`BodyCollider.buildSamples`) берутся
точки поверхности: **16 на кисти** (с пальцами), **10 на предплечье**, **8 на плече** (дальняя от сустава половина) —
вершины с весом этих костей ≥ 0,6, самые далёкие друг от друга, + мех по нормали (`SURF_FUR` 0,002 роста; `_FURLEN` на
кисти у v1/v2 = 0). Каждая хранит смещения в системе своих костей скина (до 4) и веса; каждый кадр — скин на ЦП только
этих точек (Σ w·boneMatrixWorld·u). Пары «точка : прокси», где точка внутри уже в позе покоя (рукав у капюшона), не
проверяются.

- точки поверхности проверяют **голову и одежду на ней** (`SURF_PROXY`: голова, шея, уши, кепка, наушники, капюшон,
  шарф, бант) с зазором `SURF_MARGIN` 0,004 роста (≈ 0,3 мм на карте);
- о торс, бёдра, юбку рука проверяется, как раньше, точками на осях (кисть/предплечье — 0,028; рука вдоль тела и «в
  карманах» касается худи по замыслу, её поверхность так и устроена);
- **кольца** (дуга наушников, шарф): предплечье/плечо, оказавшиеся внутри трубки со стороны центра кольца (продеты клипом
  между шеей и дугой), выходят наружу, а не к шее (`ringSide`, `RING_MIN`);
- голень и колено — только о другую ногу (о торс и юбку ноги «трутся» по замыслу — их ведёт скин), скрещённая нога
  считается прошедшей насквозь до своей стороны.

## Коррекция

**Рука с точками поверхности** (`pushChain`): за шаг — все проникшие пары «точка : прокси» руки (поверхность у головы +
точки на осях о торс/бёдра) как ограничения по нормали выхода n·Δp ≥ d; неизвестные — малые повороты предплечья (2 оси,
без кручения вдоль кости), плеча (3) и кисти в запястье (3; почти выключено — `HAND_COST` 10⁶: наклон кисти давал
щелчки кисти и застревания лапы в наушниках v1); затухающие наименьшие квадраты (плечо в `ARM_COST` = 30 раз
«дороже» локтя, пока локтем не выходит), активное множество (точки рядом, до `NEAR` снаружи, тоже
дают строки, если шаг их вталкивает), самая глубокая точка выходит целиком (до ×3), ≤ 25° на кость; точки на осях
(о торс/бёдра/юбку) — с мягким входом, как раньше (во внешней половине зазора толкание растёт как d²/2·полоса). Шаг с возвратом:
сумма квадратов глубин должна уменьшиться, иначе — полшага (до 4 раз), так руку не «бросает» между головой, наушником и
грудью. Шагов за кадр — 4 (в клипе-контакте 8), остальное добирает следующий кадр: **тёплый старт** — поправка прошлого
кадра, уже затухшая на этот (τ 0,08 с, не быстрее 5 рад/с).

**Ноги и модели без точек поверхности** — как раньше: точка внутри прокси → кость поворачивается вокруг сустава на
минимальный угол (голень — бедро вокруг тазобедренного), ≤ 25° за итерацию, до 24 итераций, всего ≤ 2 рад на кость.
Карманы: кисть в зоне кармана ложится на поверхность без зазора, глубже — выталкивается.

**Контакт вместо проникновения** (`CONTACT_CLIPS`: закрыть уши, плакать, почесать, думать, ткнуть в голову/щёку, покой в
наушниках): лапы по замыслу лежат на голове/наушниках/ушах — зазор меньше (`CONTACT_MARGIN` 0,0015 роста), а ближайшая
точка кисти, зависшая над поверхностью ближе `CONTACT_BAND` (0,03 роста), подтягивается на неё (со спадом к краю полосы —
без щелчка на входе). Вес контакта входит и уходит линейно за 100 мс (`CONTACT_FADE`).

**Сглаживание:** растущая поправка — сразу, но не быстрее 10 рад/с; уходящая — затухает в тёплом старте (τ 0,08 с, не быстрее
5 рад/с). Рука далеко от головы (ни одного прокси головы рядом) — точками на осях, как раньше: общий шаг
по торсу/бёдрам/юбке в танце и сальто давал «щелчки» 17–26 рад/с. `?collide=axis` — коррекция как 18.11–19.11 (кисть по осям, без контакта), замер — по поверхности (стенд,
листы «до»); `?collide=legacy` — как до 18.11; `?collide=0` — без коррекции.

**Цена:** кэш кадра (обратные матрицы и ограничивающие сферы прокси, центры карманов и колец), отсев по сферам (рука у
тела — ни одного прокси головы рядом, дальше ничего не считается), матрицы — только поддеревьев повёрнутых костей.

## Замер и пороги

- `BodyCollider.measurePairs()` — глубина по парам «часть тела : прокси» (`LHand:cap`, `RKnee:thigh_L`…), доли роста;
  мм на карте = × рост кота (≈ 77 мм, `CAT_MM`). Кисть, предплечье и плечо у головы — **по тем же точкам поверхности**
  (что видно), прочее — точки на осях.
- Стенд реакций (`scripts/qa/reactions.mjs`, `reactions-probe.js`): каждый кадр 30 к/с — самая глубокая пара; сценарий
  с проникновением **> 1 мм** после коррекции — «плохо»; таблица «Проникновение» в docs/qa/REACTIONS.md (до → после).
- Руки у головы крупно (`tools/hands-probe.{html,mjs}`, dev-сервер vite): 8 клипов «лапы к лицу/ушам/шее» подряд 30 к/с
  для каждой модели (v1, v2) и кота — клип как есть / «до» (`axis`, прокси как были) / «после»; листы худших кадров
  `docs/qa/hands/<v>_<кот>_<клип>.png`, позы — `bench-out/hands/*.json` (→ `scripts/models/penetration.py --pose-json`,
  сетка против сетки), время коррекции на кадр (`--throttle 4` — ЦП ×4 медленнее, «телефон»).
- Клип Meshy при загрузке (`GlbCharacter.penetration`): 8 кадров клипа на временном миксере → коррекция → замер; глубже
  **5 мм** — клип отвергается (лог `[meshy] id: отвергнут — проникновение …`, `?meshyreport`), играет прежний клип.

## Формат `<кот>_colliders.json` (для модельщика)

Координаты — в пространстве модели (GLB как есть: рост ≈ 1, стоит на Y = 0, лицом к +Z, поза покоя/привязки), метры
модели. Кость — имя без префикса `mixamorig` (`Head`, `Neck`, `Spine1`, `Hips`, `LeftUpLeg`…).

```json
{
  "version": 1,
  "volumes": [
    { "name": "head",       "bone": "Head",   "type": "ellipsoid", "center": [0, 0.78, 0.01], "radii": [0.2, 0.17, 0.18] },
    { "name": "cap",        "bone": "Head",   "type": "hull", "points": [[0.2, 0.9, 0.1], [-0.2, 0.9, 0.1], [0, 1.0, -0.2]], "mesh": "Cap_Hooligan" },
    { "name": "headphones", "bone": "Neck",   "type": "capsule", "a": [-0.12, 0.62, 0.02], "b": [0.12, 0.62, 0.02], "r": 0.05, "mesh": "Headphones_Hooligan" },
    { "name": "thigh_L",    "bone": "LeftUpLeg", "type": "capsule", "a": [0.07, 0.42, 0], "b": [0.07, 0.24, 0], "r": 0.06 }
  ],
  "pockets": [{ "bone": "Spine1", "center": [0.08, 0.38, 0.13], "r": 0.04 }]
}
```

- `ellipsoid` — центр и полуоси по осям модели; `capsule` — концы `a`, `b` и радиус `r`; `hull` — точки выпуклой
  оболочки (рантайм берёт описанный эллипсоид +5 %).
- `mesh` — прокси работает, только пока этот меш виден (одежда другого характера в общем GLB).
- Имена `thigh_L/R`, `shin_L/R` — ноги (своя нога себе не мешает).
- Реквизит (кружка, зеркальце, кисть) держит рука — прокси не нужен.
- Пересчитать: `cd scripts/models && python3 colliders.py <кот> ../../public/models/<кот>_v1.glb ../../public/models/<кот>_v1_colliders.json`
  (v1), то же с v2 GLB → `public/models/v2/<кот>_colliders.json`.
