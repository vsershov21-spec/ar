# Лицо кота: настоящий рот, веки, румянец

Модели Tripo — с нарисованным лицом без геометрии. Риг строится скриптами Blender (headless, `bl/bin/python` — `pip install bpy`):

```
bl/bin/python scripts/models/blender/face_photo.py -- /tmp/<n>_full.glb facew/<n>.npz      # фронтальный «снимок» головы
python3 scripts/models/blender/face_detect.py facew/<n>.npz facew/<n>.json facew/<n>_viz.png  # нос, глаза, линия рта (проверить viz)
bl/bin/python scripts/models/blender/face_rig.py -- /tmp/<n>_full.glb facew/<n>.json facew/<n>_face.glb /tmp/fr_<n>  # риг + превью
python3 scripts/models/glb_textures.py facew/<n>_face.glb public/models/<n>_v1.glb
```
(`/tmp/<n>_full.glb` — модель с хвостом и ушами, docs/RIG.md.)

Что получается (все накладки повторяют поверхность головы и висят на кости Head):
- **Mouth** — полость рта: тёмная, язык снизу, полоска зубов. В покое сжата в нарисованную линию рта (не видна). Ключи: mouth_A/E/O/U/M (липсинк), tongue_out, smile, smirk. Полость прилегает к лицу *с уже опущенной челюстью* для своего ключа — не прячется под мордой.
- **Основной меш**: челюсть опускается вместе со ртом (mouth_*), уголки рта вверх (smile), щёки надуваются (cheeks_gum).
- **EyeLids** — веки цвета меха (цвет берётся с текстуры над глазом, sRGB → линейный) с линией ресниц: blink_L/R, wink_L/R, eyes_squint.
- **Blush** — румянец на щеках (blush).

Имена ключей — content/face.json morphTargets; пресеты эмоций, моргание и липсинк уже их двигают (glbCharacter). (v1; брови, eyes_wide и eyes_spiral — в v2 ниже.)
Ограничения: у Блёстки длинные нарисованные ресницы выглядывают над закрытым веком; рот «О» узковат.


## v2: 3D-глаза, брови, эмоции, складки (стадия `scripts/models/face_detail.py`)

Стадия идемпотентная и работает прямо с `public/models/<n>_v1.glb` (без Blender, ≈10 с на кота): всё своё помечает
`extras.faceStage`, при повторном запуске удаляет и строит заново, чужое (стадия тела `BD_*`) не трогает. Ориентиры лица —
`scripts/models/face_landmarks/<n>.json` (копия facew/<n>.json, координаты Blender).

```
git pull --rebase --autostash
for n in hooligan kind glitter; do python3 scripts/models/face_detail.py $n public/models/${n}_v1.glb public/models/${n}_v1.glb; done
# контактный лист эмоций: npx vite --port 4177 &  PAGE=eye-preview node tools/face-shot.mjs out.png "m=/models/kind_v1.glb&s=neutral,laugh,dizzy&cols=3"
```

| что | как устроено |
|---|---|
| глаза | `Eye_L/R` (дочерние к кости Head, +Z — вперёд по нормали щеки) → `EyeS_*` (масштаб эллипсоида A, B, C) → `EyeBall_*` (сфера, текстура белок/радужка/зрачок 512 px), `LidUp_*`, `LidLo_*` (оболочки 1.035/1.015 с линией ресниц; у Блёстки — три ресницы у внешнего уголка). Края век повторяют нарисованный разрез (у Хулигана открыт шире). В extras узла: углы закрытия век, радиус радужки, веко в покое. |
| рантайм глаз | `src/character/eyeRig.ts`: взгляд на камеру (или `lookAt`) с микросаккадами, в покое — иногда в сторону, при тапе по экрану — на точку тапа (`reach`). Веки — поворот оболочек: моргание, подмигивание, прищур, смех «дугой», сонный взгляд, шире при удивлении, наклон при злости/грусти, верхнее веко следует за взглядом. Шейдер яблока: размер зрачка (`pupils` пресета), спирали головокружения (`eyes_spiral`), два блика в пространстве камеры. |
| брови | накладка `Brows` (дочерняя к Head) с ключами `brow_up`, `brow_down`, `brow_sad`; мех лба двигается теми же ключами тела. |
| ключи тела (sparse) | `brow_up/down/sad`, `cheek_up` (щёки вверх), `frown` (уголки рта вниз, нижняя губа вперёд), `nose_wrinkle`; `frown` — и у накладки Mouth, `cheek_up` — у Blush. |
| складки | `src/character/faceWrinkles.ts` — рельеф в шейдере тела по весам: гусиные лапки (смех, прищур, подмигивание), морщинки на переносице и складка между бровей (недовольство), носогубные дуги (улыбка), складка под глазом (щёки вверх), полоски на лбу (брови вверх), румянец (`blush`). Ориентиры — `extras.marks` узла Brows. |
| усы, щёки | `Whiskers` — 6 тонких лент; `FaceTufts` — ~32 карточки меха по силуэту щёк (alphaTest), у Добряка ещё вихры на макушке. |
| закраска | нарисованные Tripo глаза (и ресницы Блёстки) закрашены мехом из кольца вокруг (повтор даёт тот же результат), в rm и normal — ровный мех. Старая накладка `EyeLids` удаляется. |
| high-poly | `scripts/models/blender/bake_head.py` пекёт нормали и AO головы с high-poly Tripo на текущую сетку; `face_detail.py … --bake /tmp/bake/<n>` смешивает их с процедурным мехом (только тексели головы, AO в цвет — один раз). |

Псевдоключи век (их читает только eyeRig): `eyes_laugh`, `eyes_smug`, `eyes_sleepy`, `eyes_wide`, `eyes_spiral` + `blink_*`, `wink_*`, `eyes_squint`.

### Эмоции

`GlbCharacter.setEmotion(name, weight = 1, durationMs = 1500)` — пресет `content/face.json` поверх лица реплики, плавно входит и
уходит (0 мс — держится до следующей), `clearEmotion()`. Липсинк накладывается поверх: рот при речи виден всегда.
События сценария → эмоции — `src/character/emotions.ts` (вызывает director в `react` и `speakEvent`):

| эмоция | где срабатывает |
|---|---|
| laugh — смех, глаза дугой | тап по коту, по животу, шутка, отгадал загадку |
| happy — улыбка, щёки вверх | тап по голове (Хулиган — ухмылка, Блёстка — подмигивает), спасибо, сальто/прыжок/танец |
| smug — ухмылка с прищуром | Хулиган: тап по голове, двойной тап, «спасибо» |
| wink_l / wink_r | двойной тап, «без имени» |
| surprised — глаза шире, брови вверх, рот «о» | нашлась карта, тап по лапе/хвосту, проснулся, отклеил стикер |
| pout — надулся, морщинка у носа | тычки (комбо, сильный тычок), грубость |
| shy — румянец, взгляд в сторону | поглаживание, комплимент |
| sad — брови домиком | грусть ребёнка, страх, карта потеряна |
| sleepy — полуприкрытые глаза | долгая тишина, скука |
| dizzy — спирали в глазах | встряска телефона |
| sleep — глаза закрыты | сон (до пробуждения) |

Ещё: брови подпрыгивают на ударных слогах речи (faceLife), микромимика в покое осталась.
