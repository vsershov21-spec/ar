## v2b (19.11, только `?models=v2`)

Почему v2 «темнее и грязнее»: снимки `v2_app_*` сделаны на vite dev (lab) — там сцена тёмная и для v1 тоже; в одинаковых
условиях (сборка, пилот, кадр tom_ar) v2 темнее v1 лишь слегка. Реальные причины: сжатие глаз к центру (×0.82–0.88) ужало
межглазье D → маски светлой морды furTone (в долях D) стали меньше; тяжёлое веко restUp 0.4/0.34 → сонный хмурый взгляд;
кончики карточек таяли сильнее (светлые кончики — яркость меха); заплатки старых наушников красились смесью меха и худи;
фатин брал текстуру юбки Tripo по UV ближайшей вершины → серая рябь. Исправлено:
- `head_shape.py`: глаза ×0.958 от v1 (eye 0.05), ниже вдвое меньше; `fur_volume.py`: restUp = v1 + 0.05 (0.35/0.32/0.22);
- `headphones.py`: чашки R ×1.22 (≤ 0.05), толщина ×1.35, ось вперёд-наружу (лежат на капюшоне), дуга — лента 19 мм,
  широкая по высоте, крепится к краю чашки сзади-сверху; заплатки: класс мех/худи — гармонически от краёв, худи — общий тон,
  размытие; `tulle.py`: фатин без текстуры — ровный мятный тон, альфа ровнее;
- рантайм v2: `FUR_V2` (кончики тают 0.4, «в лоб» как v1), `FUR_TONE_V2` (мех на тон светлее, морда сильнее).
Листы: `v2b_app_<кот>.png`, `v2b_kitchen_glitter.png` (слева v1, справа v2), `v2b_faces.png` (v1 | v2b, 3/4 и анфас).

Сборка из GLB после `body_detail.py` (для текущих моделей — `git show bb768e9^:public/models/<cat>_v1.glb` → `<base>/<cat>.glb`):

Стадии (все без Blender, numpy/scipy, кости и веса не меняются):
1. `head_shape.py` — гладкая объёмная деформация головы по точкам лица (extras.marks): щёки-«баки» шире и ниже, череп

2. `headphones.py` (Хулиган) — старая спаянная поверхность наушников натянута гармонической мембраной (без дыр), её
