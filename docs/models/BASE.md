# База котов + скины (26.11, ветка `cat-base`, `?models=base`)

Решение продакта: «отдельные модели по мимике не нужны — Хулиган, Добряк и Блёстка должны отличаться только скином,
механика общая». Поэтому один кот (база) и три скина на тот же скелет.

## Сборка одной командой

    sh scripts/models/build_base.sh [/tmp/cat_base]      # ≈ 4 мин, без Blender-окна и генераций (кредиты Meshy/Tripo — 0)
    SKINS_ONLY=1 sh scripts/models/build_base.sh          # только скины и прокси (база уже собрана)

Нужны `/tmp/bpyenv/bin/python` (pip install bpy==5.3.0 numpy scipy pillow) и `python3` с numpy/scipy/pillow/matplotlib.
Входы: `design/models/glitter_tripo_rigged.glb` (Tripo-Блёстка продакта, форма p4 v3) и `public/models/v2/{hooligan,kind}_p1.glb`
(кепка Хулигана, шарф и сапожки Добряка), `public/models/v2/hooligan_v2.glb` (наушники headphones.py).

Выход — `public/models/base/`:

| файл | что | сжато (model-opt) |
|---|---|---|
| `cat_base.glb` | база: тело + голова, скелет Mixamo 65 + LeftEar1/RightEar1 + Tail1..4, риг лица на морфах, глаза/веки/ресницы, полость рта, клычки, язык, мех-оболочки | 2.06 МБ (кэшируется один раз на все коты) |
| `skin_glitter.glb` | худи Tripo, пачка-фатин (alpha), бант со звездой и звёзды, золотой кант; блёстки хвоста — рантайм | 1.12 МБ |
| `skin_hooligan.glb` | чёрное худи с лаймовым кантом (шаблон), кепка p1, наушники v2, кеды по стопе базы | 0.73 МБ |
| `skin_kind.glb` | кремовое худи с мятным кантом (шаблон), шарф и сапожки p1 | 0.86 МБ |
| `skin_<кот>_colliders.json` | прокси столкновений по базе со скином (`colliders.py`) | — |

Загрузка на телефоне: первый кот — база + скин ≈ 2.8–3.2 МБ (p1 — 3.1–3.3), каждый следующий — только скин 0.7–1.1 МБ;
три кота вместе ≈ 4.8 МБ вместо 9.65 МБ у p1.

## Стадии

1. **Форма и лицо** — конвейер Блёстки p4 v3 (`build_glitter_p4.sh`) в рабочую папку со своими ориентирами
   (`face_landmarks/cat_base.json`) и параметрами (переменные окружения, по умолчанию — как у p4):
   * `P4_MOUTH_W=2.6`, `P4_MOUTH_SMOOTH=0.8` (`glitter_p4_land.py`) — рот шире (≈ 0.68 межглазья, как у рефа
     design/sheets/mouths.jpg) и линия рта ближе к гладкой дуге: по «ω» с острым пиком разрез губ рига p2 не отделял губы
     у середины;
   * `P4_MUZZLE='{"step": 0.0026}'` (`glitter_p4.py`) — мордочка реже (размер файла: FaceSkin 38 → 16 тыс. вершин);
   * `FR_OVR` (`face_rig.py`): челюсть 0.22, проём шире (`open_k` 1.5) и «D» площе (`prof_p` 0.4), язык за челюстью
     слабее (`tongue_jaw` 0.8 — у плоской морды кончик выходил сквозь подбородок); `MOUTH_OVR` — «о», «у», «удивление»
     круглее и шире;
   * в `face_rig.py` починено: Т-стыки подразбиения у края зоны SUBDIV (трещины под нижней губой) считались краем
     морды — маска «у края 0» гасила челюсть (нижняя губа не опускалась — «зуб» кожи в открытом рте). Теперь малые
     куски граничных рёбер (< 40 вершин) — не край.
2. **База** — `base_build.py`: одежда Tripo (роль cloth), пачка и золото — прочь; под худи у Tripo тела нет — торс
   `BodyTorso` (оболочка худи и рукавов к оси костей на 12 мм, ворот уже) отдельным узлом на буферах тела, его прячут
   скины в худи (вид базы без одежды — кот); мех-оболочки на новых буферах; атлас: плитки одежды — тон меха, плитка худи —
   градиент «мех → светлая грудка» для торса, хвост без блёсток, звёзды/бант в текстуре головы и серые пятна Tripo на
   макушке закрашены мехом; закрыта дыра на макушке.
3. **Скины** — `skin_build.py <кот>`: GLB с тем же скелетом (узлы и inverseBindMatrices базы) и только одеждой:
   * Блёстка — из p4m как есть (худи, пачка, бант/звёзды), атлас — плитки p4;
   * Хулиган, Добряк — худи Блёстки как шаблон (сидит на торсе без подгонки): перекраска плиток (лиловое → основной цвет,
     мята и золото → кант, значок), подол длиннее (+70/60 мм) и шире к низу; кепка и шарф/сапожки p1 — перенос LBS
     (вершина едет с костями p1 → кости базы), кепка — масштаб по голове базы без ушей + дыры под уши, наушники v2 —
     уменьшены к шее и жёсткая подгонка (растяжение от оси шеи), кеды — оболочка стопы базы, цвет вершин (чёрный верх,
     белые подошва и шнурки); затем выталкивание из тела базы (зазор 3–4 мм, поле сглажено по сетке одежды; нормали тела —
     наружу по оси ближайшей кости: у частей Tripo обход бывает вывернут);
   * краска одежды, которую у p1 делал рантайм (`FUR_TONE_*.cloth`), запечена в атлас скина;
   * `asset.extras.catSkin` — вид: лицо в покое (`rest`), множители век (`eyes`), `restUp`, толщина подводки `lash`,
     лепестки ресниц `petals` (0 — убрать), `hide` (BodyTorso), `furOff` (кости стоп: мех не сквозь обувь), `fx`
     (`tailSparkle` — блёстки хвоста Блёстки), тон бровей `brow`.
4. **Прокси** — `skin_build.py compose` (база + скин одним GLB) → `colliders.py` (метки частей у скина — по имени меша).

## Рантайм

`src/character/catSkin.ts` + `glbCharacter.load()`: адрес — скин (`modelVariant.variantGlb(…, 'base')` →
`models/base/skin_<кот>.glb`), по его `extras.catSkin` грузится база (`fetchModel`, HTTP-кэш: один файл на всех котов;
`app.ts` прелоадит базу вместе со скином), `graftSkin` переносит меши скина в сцену базы и привязывает к её костям по
имени, `applySkinLook` — вид до разбора характера. Дальше всё как у одной модели: мимика (`faceMorphs`), `eyeRig`,
хват (`gripSolver`/`propPen`), коллайдеры, footPin, кровать — один набор настроек; одежду скина `furTone` не тонирует,
тон меха — один на всех (`FUR_TONE_P4.glitter`, `furTone.setBase`); лицо покоя уступает эмоции (×(1 − 0.85·сила)).

Включение: `?models=base` (lab; MVP и пилот — только со страницы /test, `?from=test&models=base`). По умолчанию нигде —
пилот /mvp не меняется до приёмки продактом.
