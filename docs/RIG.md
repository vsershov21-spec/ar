# Скелет кота: хвост и уши

Tripo делает гуманоидный скелет Mixamo (65 костей) — без хвоста и ушей. Достраиваем в Blender (headless, `pip install bpy`, Python 3.11):

```
python3.11 -m venv bl && bl/bin/pip install bpy scipy numpy
# 1) вершины, рёбра, цвет текстуры, кости → /tmp/<n>.npz
bl/bin/python scripts/models/blender/dump.py -- models/<n>_rig.glb /tmp/<n>.npz
# 2) поиск хвоста (узкое позади спины, ниже корня — юбка, не берём) и ушей (вверх от макушки) → /tmp/<n>_parts.npz
python3 scripts/models/blender/find_parts.py <n>
python3 scripts/models/blender/viz_parts.py          # /tmp/parts.png — проверка глазами (красный хвост, синие уши)
# 3) кости Tail1..Tail4 (от mixamorig:Hips) и LeftEar1/RightEar1 (от mixamorig:Head), веса, экспорт
TA=12 bl/bin/python scripts/models/blender/rig_cat.py -- models/<n>_rig.glb /tmp/<n>_parts.npz /tmp/<n>_full.glb /tmp/rt_<n>
# 4) текстуры → JPEG ≤1536 px
python3 scripts/models/glb_textures.py /tmp/<n>_full.glb public/models/<n>_v1.glb
```

Веса хвоста: по геодезическому расстоянию от корня, линейная смесь соседних сегментов, у корня плавно в таз (12 % длины).
Уши: от основания к кончику, остальное — голова. Поза покоя костей Mixamo после Blender совпадает с исходной (проверено: 0 расхождений из 65) — библиотека движений `anims_v1.glb` играет как раньше.

## Движение хвоста и ушей — `src/character/tailRig.ts`

Клипы Mixamo хвост и уши не двигают, поэтому поверх любого клипа работает TailRig:

| режим | когда | что делает |
|---|---|---|
| idle | покой | медленно водит, блуждает, Хулиган щёлкает кончиком |
| wag | радость, смех, прыжки, `tail_wag` | машет, волна к кончику |
| puff | испуг, `tail_puff` | трубой вверх, дрожит, уши торчком |
| sad | грусть, плач, падение | опущен, уши вниз |
| angry | обида, раздражение | хлещет, уши прижаты |
| curious | слушает, думает | кончик крючком, уши поворачиваются |
| walk / run | ходьба, бег | качается в шаг, на бегу вытянут |
| dance | танцы, праздник, песня | широкий взмах в такт |
| sleep | сон | обёрнут, едва шевелится |
| purr | гладят | поднят, мелко дрожит |
| whip | ткнули в хвост, вздрогнул | резкий взмах вверх |

Характер задаёт манеру: Хулиган — ленивый со щелчками кончиком, Добряк — плавный и широкий, Блёстка — пружинит и машет чаще.
Каждый канал — пружина (кончик мягче — запаздывает), поворот и прыжок тела отбрасывают хвост по инерции.
Уши: уровень из пресета лица, сами подёргиваются раз в 2,5–7 с, `ear_twitch` / `ears_back`, покачиваются, пока кот говорит.

Просмотр: `npx vite` → `/tools/tail-preview.html?p=glitter&m=dance&yaw=200` (p: hooligan|kind|glitter, m: happy|sad|puff|angry|dance|walk|sleep).

## Движения тела: подготовка клипов и переходы — `animPrep.ts`, `animBlend.ts`

Библиотека `anims_v1.glb` склеена из трёх выгрузок Tripo (три копии скелета). GLTFLoader делает имена узлов уникальными (`mixamorigHips_1`, `…_2`), поэтому 10 клипов второй/третьей выгрузки (idle_tail_play, talk_excited, celebrate, sleep_loop, stand_up, wake_startle, dizzy, hug_screen, snowglobe_shake, echo_speak) раньше не находили костей — кот стоял в bind-позе с разведёнными руками. При загрузке `prepareClips` (animPrep.ts):

1. перепривязывает треки к костям модели (суффикс `_N` срезается);
2. пересобирает кривые в 30 к/с и сглаживает по Гауссу (σ 0,75–1,6 кадра по шуму T2M), петли — по кругу;
3. у одноразовых клипов срезает неподвижные начало/хвост (реакция начинается сразу, запас 0,1 с);
4. закрывает шов петель перекрёстным смешиванием конца с началом (talk_casual «щёлкал» раз в 5 с — шов 1,05 рад → 0);
5. корень: горизонталь фиксирована (место держит сцена), высота — по самой низкой опоре за клип (лапы/колени/кисти не под картой, клип не парит; прыжки сохраняются); сон сдвигается, чтобы лежал на карте;
6. слишком резкие клипы (p95 угловой скорости > 8 рад/с, кроме танцев/бега/прыжков) замедляются до ×0,8.

Переходы (animBlend.ts) — инерциальные: новый клип сразу играет с весом 1, а разница «показанная поза − новая» затухает за 0,15–0,6 с (в покой — smootherstep, в реакцию — быстрый старт). Ни bind-позы, ни «щелчков» при частых тапах (пик угловой скорости при спаме тапов 57 → ~12 рад/с). Каждый кадр кости сначала возвращаются к чистому выходу миксера: three.js пишет в кость только изменившееся значение, и поправки поверх клипа (взгляд, выталкивание рук) на неподвижных треках копились бы. В покое — слой «перенос веса» (медленные покачивания корпуса), случайная фаза и темп ±8 % у петель покоя. Ходьба: темп клипа под скорость сцены (`object.userData.moveSpeed` из Stage).

Сравнить «как было»: `?anim=raw`. Замеры: `node tools/anim-diag.mjs <tag> [persona] ['&anim=raw']` (сервер `npx vite --port 4191` или `vite preview`) → `docs/look/anim_<tag>.json`: pop (пик скорости в первые 0,35 с после смены клипа), bind, высота лап. Аудит кривых без браузера: `node tools/anim-audit.mjs public/models/anims_v1.glb`.

Поворот к зрителю (stage.ts): пружина с ограничением скорости (к зрителю 2,6 рад/с, в ходьбе 5), гистерезис ~7° против дрожания трекинга, не зависит от частоты кадров; шаг начинается, когда кот почти развернулся.

Блёстка p4 (модель Tripo «по частям»): уши и хвост — отдельные части, `scripts/models/blender/p4_parts.py` берёт их
целиком вместо `find_parts.py`; `dump.py` читает цвет по материалу полигона (сетка из нескольких частей). Вся сборка —
`scripts/models/build_glitter_p4.sh` (docs/models/README.md).
