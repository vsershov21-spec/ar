# Меню «как у Говорящего Тома» (feature `ui.tomLayout`)

Редакции: **пилот (/mvp) — да, lab — да, MVP — нет** (там прежний лист «Что умею»). Десктоп-панель (`?desktop`) — без изменений:
пока она включена, меню выключено.

Код: `src/ui/tomLayout.ts` (чистая логика: что где лежит, геометрия, автоскрытие), `src/ui/tomMenu.ts` (DOM),
стили — раздел «меню как у Говорящего Тома» в `src/ui/styles.css`. Контекст (комната дома, сон, раскраска, сцены) даёт
`app.ts uiContext()`. Тесты — `tests/tomLayout.test.ts`. Снимки — `node scripts/tom-shots.mjs` → `docs/ui/tom_*.png`.

## Образец: как устроен экран Talking Tom / My Talking Tom

Описание по памяти, только схема — арт, иконки, персонажи и бренд не используются (у нас свои иконки в палитре Сбера).

- **Персонаж крупно в центре.** Он занимает середину экрана, и кнопки его не закрывают: всё управление — по краям.
- **Вертикальные колонки у левого и правого края.** Круглые кнопки-иконки с короткой подписью идут столбиком вдоль
  края, там, куда достаёт большой палец, когда телефон держат одной рукой. Кнопки сгруппированы по смыслу (одна сторона —
  «что сделать с персонажем», другая — «что он умеет/во что одет»).
- **Внизу — действия комнаты.** В «My Talking Tom» у каждой комнаты (кухня, спальня, ванная, игровая) свои 1–3 кнопки
  внизу по центру (покормить, уложить спать…), а переход между комнатами — стрелками/свайпом по краям нижней полосы.
- **Сверху — немного постоянного.** Домой/назад, прогресс (уровень, монеты) — маленькими «плашками» в углах.
- **Отклик касания.** Кнопка коротко «прыгает» (сжалась — подпрыгнула), персонаж сразу реагирует; новое отмечено красной
  точкой; что-то недоступно — серое, на нажатие — короткая подсказка.
- **Никаких листов поверх персонажа.** Меню не выезжает снизу на полэкрана; редкое — в маленьком всплывающем окне у кнопки.

## Наша адаптация для AR

За котом — камера, кот стоит на карте в нижней середине кадра (дома — посреди комнаты). Поэтому:

```
┌──────────────────────────────┐
│ ★ 5/13           (Кухня ●○○) │  ← прогресс «открыто N из M»; дома — плашка комнаты (HomeMode)
│ ЛАСКА                 ТРЮКИ  │
│ (✋)     ┌ пузырь ┐     (♪)  │
│ Погладить└───────┘   Танец   │
│ (W)                    (↻)   │  ← колонки у краёв: слева «Ласка», справа «Трюки/Образ»
│ Почесать     /\_/\   Сальто  │
│ (🪶)        ( кот )    (★)   │     колонки не заходят на рамку кота (catRect)
│ Щекотка      > ^ <   Скейт   │
│ (♥)        ▬карта▬    (▣)    │
│ Обнять               К стеклу│
│ (🐾)                  (✎🔒)   │  ← неактивная: «Сначала покажи мне карту»
│ Дай лапу             Раскрась│
│ (🐟)                  (⇄)    │
│ Угостить           Другой кот│
│     [? Загадка] [♪ Танец]    │  ← 1–2 чипа кота (scenario/suggest.ts)
│  ‹    (🐟)Угостить (☕)Какао ›│  ← дома: ряд комнаты + стрелки комнат
│ (🔊) (⌂)  (  🎤  )  (🎮) (⚙) │  ← док: звук · «Мой дом»/«На карту» · микрофон · «Игры» · «Ещё»
└──────────────────────────────┘
```

**Колонки.** Слева «Ласка» — погладить, почесать, щекотка, обнять, дай лапу, угостить. Справа «Трюки/Образ» — танец,
сальто, два фирменных действия характера (Хулиган: скейт, «к стеклу»; Добряк: какао, пузыри; Блёстка: зеркальце,
блёстки), «Раскрась» (раскраска карты), «Другой кот». Источник — тот же каталог, что у листа (`buildCatalog` →
`groupCatalog`): `tomModel` только раскладывает пункты (`LEFT_ORDER`, `RIGHT_ORDER`), ничего не добавляет и не теряет.
В lab пунктов больше — последняя ячейка колонки становится «Ещё» (поповер с остальными), это второе касание.

**Кот важнее кнопок.** `tomLayout` пробует по очереди: колонка по центру высоты → прижатая кверху → то же с кнопками
поменьше (−8 px) → сетка 2×N сверху (кот обычно ниже) → язычок у края. Берётся первый вариант, где ни одна ячейка
(кружок + подпись) не заходит на рамку кота с запасом 4 px. Чтобы колонки не «дрожали», пока кот ходит, прежний режим
держится, пока он мимо кота, а на лучший переходим, только когда кот отошёл с запасом 18 px. Если ребёнок сам тянет
колонку из язычка — она встаёт поверх кота до автоскрытия.

**Низ.** Док: звук · «Мой дом» (дома — «На карту») · микрофон (главная, крупная) · «Игры» (поповер: загадка, повторяй;
в lab — ещё игры и «Фразы») · «Ещё» (шестерёнка: режим микрофона, пересадить на другую карту). Над доком — 1–2 чипа
кота. Дома над доком — ряд комнаты: кухня — угостить, какао; спальня — уложить, разбудить (неактивная, пока кот не
спит, и наоборот); гостиная — мячик, танец; по краям ряда — стрелки соседних комнат (кнопки HomeMode, переставлены
CSS), «На карту» сверху не дублируется. Действия комнаты из чипов кота убираются (не повторяются).

**Верх.** Прогресс «★ 5/13» (сколько действий уже пробовал; тап — подсказка «Ищи кнопки с красной точкой!»), дома
посередине — плашка комнаты. Пузырь реплики — под верхней полосой и между колонками; сбоку от головы — тоже только
между колонками.

**Автоскрытие.** Через 6 с без касаний колонки уезжают к краю, остаются язычки с шевроном (и красной точкой, если там
есть новое). Сразу прячутся на время сцен: пробуждение (`awake`), раскраска и лист цветов (`paint`), сон/дрёма
(`sleep`), переход домой и обратно, бег между комнатами, знакомство (`cutscene`). Касание у края экрана (≤ 30 px) или
по язычку — возвращает; после сцены колонки возвращаются сами. Пока открыт поповер или подсказка — не прячутся.

**Отклик.** Тап — «прыг» кнопки (0,5 с) и действие сразу (без закрытия листа). Красная точка — «ещё не пробовал».
Неактивная кнопка — серая с замочком; тап — «нет-нет» (покачивание) и подсказка над микрофоном («Сначала покажи мне
карту»). Долгое нажатие (0,48 с) — подсказка рядом с кнопкой, без действия. До конца знакомства кнопки дока приглушены.

**Одна рука, safe-area, альбомная.** Всё нажимаемое — у краёв и снизу (зона большого пальца), кружки 56 px (на
низких экранах 50, в альбомной 46; уменьшенный вариант колонки — на 8 px меньше), подписи до 10 знаков. Отступы — от
`env(safe-area-inset-*)` (пробник в DOM). В альбомной колонки — сетки 2×3 у краёв на всю высоту, док и чипы — снизу
между ними; ряд комнаты — на месте чипов (пока кот спрашивает — вместо него чипы).
