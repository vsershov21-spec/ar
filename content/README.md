# content/ — всё, что кот говорит и делает

Единый источник правды для реплик, диалогов, анимаций, эффектов, звуков и характеров. Приложение грузит собранные `content/personas/*.json` и каталоги напрямую (Vite кладёт каждый файл отдельным чанком с хэшем в имени — `src/persona/content.ts`); `public/personas` больше нет.

| Файл | Что внутри | Кто правит |
|---|---|---|
| `events.json` | 83 события: сценарий, касания, голос ребёнка, время | продукт |
| `src/<характер>.lines.txt` | реплики, по 2–6 вариантов на событие | сценарист, без программиста |
| `src/<характер>.meta.json` | пресет характера: голос, палитра, одежда, idle, фирменный трюк, настройки эффектов, наклейки | продукт + дизайн |
| `animations.json` | 71 клип тела с длительностью, петлёй, приоритетом P0–P2 | аниматор |
| `face.json` | 22 пресета лица (веса блендшейпов, уши, зрачки) | аниматор |
| `fx.json` | 31 экранный и мировой эффект | разработка |
| `sounds.json` | 43 звука с промптами для генерации | саунд-дизайн |
| `dialogs.json` | многоходовые диалоги (знакомство, «пока?», «к брату?», загадка, повторялка, поддержка) и загадки — по 8 на характер; схема — docs/DIALOGS.md | продукт + сценарист |
| `intents.ru.json` | голосовые намерения и фразы-синонимы | продукт |
| `names.ru.txt` | словарь имён: кот говорит имя, только если оно здесь | продукт |

## Как править реплики

Открыть `src/hooligan.lines.txt` (или `kind`, `glitter`) и писать так:

```
## tap_screen | clip=knock_glass fx=knock sound=glass_knock
cheeky: Тук-тук, чё надо?
happy: Тук-тук в ответ! [clip=wave]
```

Потом: `python3 content/build.py`. Скрипт проверяет, что у каждого характера есть реплики на все события, все клипы, эффекты и звуки существуют, нет запрещённых слов, `{name}` стоит только в разрешённых местах, и предупреждает об обращении к ребёнку с родом («ты пришёл»). При ошибке — код возврата 1, CI падает.

Скрипт пишет:
- `content/personas/*.json` — для приложения;
- `gen/voice_lines.csv` — все реплики с голосом и указаниями актёру (озвучка Piper / ElevenLabs / актёр);
- `gen/animations.csv`, `gen/fx_list.csv`, `gen/sfx_prompts.csv` — списки для генерации;
- `docs/CONTENT.md` — читаемая версия всего контента.

## Правила для всех реплик

- До 8 секунд (≈14 символов в секунду; build.py предупреждает), лучше 2–4.
- Кот о себе — в своём роде (Хулиган, Добряк — «я рад», Блёстка — «я рада»).
- Реплики веток диалогов — минимум 3 варианта; у `nice_name` и `welcome_back` хотя бы один вариант без `{name}`.
- К ребёнку — без рода: «ты тут», а не «ты пришёл».
- Не спрашиваем ничего, кроме имени (и его можно не говорить). Возраст, адрес, школу — нет.
- На «грустно» и «страшно» кот поддерживает, ничего не спрашивает и предлагает позвать взрослого. Никаких советов сверх этого.
- На грубость кот не грубит и не стыдит, переводит в игру.
- Про деньги кот не рассказывает сам — отправляет к брату в СберKids.
